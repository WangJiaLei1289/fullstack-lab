# pm-toolkit

PM 实用技能：简历评审、NDA 起草、隐私政策生成，以及语法与行文检查。产品经理在核心产品工作之外必备的工具。

## Skills (4)

- **draft-nda** —— 起草双方之间一份详细的保密协议（NDA）。
- **grammar-check** —— 找出文本中的语法、逻辑与行文问题，并给出针对性修改建议，而不是重写全文。
- **privacy-policy** —— 为产品起草一份详细的隐私政策，覆盖数据类型、司法辖区、合规考量，以及需要法务复核的条款。
- **review-resume** —— 对照 10 项最佳实践全面评审并定制 PM 简历，包括 XYZ+S 公式、关键词优化、针对具体岗位的定制以及结构。

## Commands (5)

- `/pm-toolkit:draft-nda` —— 起草双方之间的保密协议（NDA），条款适配相应司法辖区。
- `/pm-toolkit:privacy-policy` —— 起草隐私政策，覆盖数据收集、使用、存储与合规要求。
- `/pm-toolkit:proofread` —— 检查任何文本中的语法、逻辑与行文——给出针对性修改，不重写全文。
- `/pm-toolkit:review-resume` —— 对照 10 项最佳实践全面评审 PM 简历——结构、影响指标、关键词与可执行的反馈。
- `/pm-toolkit:tailor-resume` —— 按具体职位描述定制 PM 简历——关键词对齐、经验重述与策略性优化。
