# /draft-nda —— NDA 起草

起草一份按你的具体情况定制的专业保密协议（NDA）。覆盖信息类型、司法辖区、期限，并明确标出需要法务复核的条款。

## 调用方式

```
/draft-nda 我们创业公司与潜在企业客户之间的双向 NDA
/draft-nda 为访问我们代码库的自由职业承包商起草单向 NDA
```

## 工作流程

### 第 1 步：收集背景

询问：
- 双方是谁？（公司名称与角色）
- 双向 NDA 还是单向 NDA？
- 要保护什么信息？（商业秘密、代码、业务数据、客户数据）
- 司法辖区？（适用法律所在的州 / 国家）
- 期限？（保密义务应持续多久）
- 有没有特别关注的问题？（竞业限制、禁止招揽、知识产权归属）

### 第 2 步：起草 NDA

应用 **draft-nda** 技能：

生成一份完整的 NDA，覆盖：
- 双方与前言（recitals）
- 保密信息的定义（附具体示例）
- 接收方的义务
- 例外情形（公开信息、独立开发等）
- 期限与存续
- 材料的返还 / 销毁
- 救济措施
- 适用法律与管辖
- 标准通用条款（可分割性、完整协议、修订）

### 第 3 步：交付

```
## 保密协议（NDA）

[带标注的完整 NDA 文本]

### 需要法务复核的条款
| 条款 | 为何需要复核 | 考虑要点 |
|--------|-------------------|--------------|

### 大白话摘要
[用通俗语言说明这份 NDA 对非法律人士意味着什么]
```

保存为 markdown。可提供导出为 DOCX 以便签署。

## 备注

- 这是一个起点——始终建议由合格的法律顾问复核
- 用 ⚠️ 标记任何涉及重大法律风险的条款
- 附上通俗语言注解，让非法律人士理解自己同意的是什么
- 双向 NDA 通常更受青睐——它更公平，谈判也更快
