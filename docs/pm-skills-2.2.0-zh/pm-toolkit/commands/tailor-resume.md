# /tailor-resume —— 简历与 JD 匹配优化

把你的简历和一份目标职位描述放在一起，策略性地对齐你的经验，最大化面试机会。关键词优化、要点重写与差距分析。

## 调用方式

```
/tailor-resume [上传简历] 这是 JD：[粘贴职位描述]
/tailor-resume [把简历和 JD 都作为文件上传]
```

## 工作流程

### 第 1 步：接收两份文档

需要两个输入：
- 简历（文本、PDF 或 DOCX）
- 目标职位描述（文本、URL 或文件）

如果只提供了其中一个，向用户索要另一个。

### 第 2 步：分析职位描述

提取：
- 必备任职资格与技能
- 加分任职资格
- 主要职责
- 行业与领域信号
- 资历层级信号
- 文化与团队信号

### 第 3 步：定制简历

应用 **review-resume** 技能：

- **关键词对齐**：把 JD 关键词映射到简历内容，自然地补上缺失的关键词
- **要点重写**：用 XYZ+S 公式重述经验，突出与 JD 相关的成果
- **章节重排**：把最相关的经验放在前面
- **摘要 / 目标**：改写成直接回应这个岗位
- **技能章节**：与 JD 要求对齐

### 第 4 步：生成定制简历与分析

```
## 简历定制：[公司] 的 [职位名称]

### 匹配度评分：[X/10]

### 关键词差距分析
| JD 关键词 | 简历中是否有？ | 建议 |
|-----------|-----------|---------------|

### 已做的修改
1. **[章节]**：[改了什么、为什么]
2. ...

### 定制后的简历
[重写后的完整简历文本]

### 差距分析
**强匹配**：[你的经验直接对齐的地方]
**重述匹配**：[经验被重新定位以贴合要求的地方]
**差距**：[JD 要求中你未清晰回应的部分——附建议]

### 求职信要点
[求职信中应强调的 3-4 个点，用于弥合剩余差距]
```

将定制后的简历保存为 markdown。

## 备注

- 绝不编造经验——如实重述，不要杜撰
- 摘要 / 目标是每次投递中最值得定制、回报最高的章节
- 尽量精确匹配 JD 的用词（如果他们说「跨职能」，就用「跨职能」）
- 对高级岗位，强调规模与战略影响；对个人贡献者（IC）岗位，强调亲手落地执行
