# /review-resume —— PM 简历评审

对照产品管理最佳实践，对你的简历做一次全面评审。评估结构、影响指标、关键词优化，并给出带示例的具体改进建议。

## 调用方式

```
/review-resume [粘贴简历文本]
/review-resume [上传简历 PDF 或 DOCX]
```

## 工作流程

### 第 1 步：接收简历

接受粘贴的文本、上传的 PDF 或 DOCX 文件。解析完整内容。

### 第 2 步：对照 10 项最佳实践评估

应用 **review-resume** 技能：

1. **影响指标**：成果是否被量化？（收入、用户数、转化率）
2. **XYZ+S 公式**：「以 [Y] 衡量，完成了 [X]，通过做 [Z]，其中用到 [S 技能/工具]」
3. **PM 专属语言**：使用产品术语（上线、主导产品发现、定义战略）
4. **结构与可读性**：章节清晰、格式一致、便于扫读
5. **关键词优化**：匹配常见 PM 职位描述中的关键词
6. **职业叙事弧线**：体现职业成长与职责范围的扩大
7. **简洁**：初级一页，资深最多两页。不要注水。
8. **相关性**：经验针对 PM 岗位定制，而非泛泛而谈
9. **技术可信度**：体现与工程、数据、设计协作的能力
10. **领导力信号**：跨职能影响力、利益相关方管理、带人

### 第 3 步：生成评审报告

```
## 简历评审

**总分**：[X/10]
**最强项**：[哪项最佳实践]
**最大提升空间**：[哪项最佳实践]

### 评分卡
| # | 最佳实践 | 得分 | 评估 |
|---|-------------|-------|-----------|
| 1 | 影响指标 | [/10] | [简短评估] |
| 2 | XYZ+S 公式 | [/10] | [简短评估] |
| ... | ... | ... | ... |

### 前三项改进

**1. [影响最大的改动]**
- 现状："[简历中的原文]"
- 建议："[改进版本]"
- 原因：[理由]

**2. [第二项改进]**
[同样的格式]

**3. [第三项改进]**
[同样的格式]

### 逐节反馈
[针对简历每一节的具体说明：摘要、经历、教育、技能]

### 缺失要素
[PM 简历本应有却缺失的内容]

### 建议补充的关键词
[简历中缺少、但在典型职位描述里常见的 PM 相关关键词]
```

### 第 4 步：提供后续动作

- 「要我**按具体职位描述定制这份简历**吗？」
- 「要我**用 XYZ+S 公式重写某些要点**吗？」
- 「要我**基于这份简历生成一封求职信**吗？」

## 备注

- 要具体、有建设性——「加点指标」没有用，「把『改进了新手引导』改成『把新手引导流失率降低 23%（450 → 347 人/月）』」才可执行
- PM 简历应强调结果而非产出，强调影响力而非职权
- ATS（申请人跟踪系统）优化很重要——自然地写入相关关键词
- 不同 PM 层级期望不同：APM = 潜力，高级 PM = 影响力，总监及以上 = 规模
