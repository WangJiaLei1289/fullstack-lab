# /proofread —— 语法与行文检查

找出文本中的语法、逻辑与行文错误。给出具体、针对性的修改，而不重写整份文档。

## 调用方式

```
/proofread [粘贴文本]
/proofread [上传文档]
```

## 工作流程

### 第 1 步：接收文本

接受任何形式的文本：粘贴的、上传的文档（DOCX、PDF、markdown），或邮件草稿。

### 第 2 步：分析

应用 **grammar-check** 技能：

扫描三类问题：

**语法**：拼写、标点、主谓一致、时态一致性、冠词用法
**逻辑**：矛盾、无支撑的断言、循环论证、指代不清
**行文**：生硬的过渡、句子节奏、段落结构、冗余、可读性

### 第 3 步：报告问题

```
## 校对报告

**文本长度**：[字数]
**发现问题数**：[按类别计数]

### 问题清单

#### 1. [类别：语法/逻辑/行文]
- **位置**："[含问题的原文引用]"
- **问题**：[哪里不对]
- **修改**："[修改后的文本]"

[对每个问题重复]

### 汇总
- 语法：[X] 个问题
- 逻辑：[X] 个问题
- 行文：[X] 个问题
- 整体质量：[评估]
```

### 第 4 步：提供后续

- 「要我**应用全部修改**并把清理后的文本给你吗？」
- 「要不要**针对某一节**做更细的检查？」

## 备注

- 修改建议应尽量小——只改必要之处，保留作者的文风
- 对非英语母语者，尤其要把*为什么*建议这样改说清楚
- 不要过度纠正风格偏好——「错误」和「不同」是两回事
- 对专业文档，还要检查语气一致性与受众适配度
