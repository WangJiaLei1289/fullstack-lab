# /privacy-policy —— 隐私政策生成器

为你的产品起草一份完整的隐私政策。覆盖数据类型、司法辖区、合规要求（GDPR、CCPA），并标出需要法务复核的条款。

## 调用方式

```
/privacy-policy 收集用户行为数据的 SaaS 分析工具——服务美国与欧盟客户
/privacy-policy 带位置数据和第三方集成的移动应用
```

## 工作流程

### 第 1 步：收集背景

询问：
- 是什么产品或服务？
- 收集哪些数据？（个人信息、使用数据、Cookie、位置、支付）
- 你的用户在哪里？（决定适用的法规：GDPR、CCPA 等）
- 是否有第三方数据共享？（分析、广告、集成）
- 数据存储：存在哪里、存多久？
- 年龄限制？（COPPA 相关考量）

### 第 2 步：起草政策

应用 **privacy-policy** 技能：

生成覆盖以下内容的章节：
- 收集哪些数据以及如何收集
- 数据如何被使用（目的）
- 处理的合法性基础（GDPR）
- 数据共享与第三方
- 数据保留与删除
- 用户权利（访问、删除、可携带、退出）
- Cookie 政策
- 安全措施
- 儿童隐私（如适用）
- 跨境传输
- 联系方式
- 政策更新流程

### 第 3 步：交付

```
## 隐私政策：[产品]

[完整政策文本]

### 合规检查清单
| 法规 | 状态 | 说明 |
|-----------|--------|-------|

### 需要法务复核的条款
| 条款 | 原因 | 优先级 |
|--------|-----|----------|

### 实施检查清单
- [ ] Cookie 同意横幅
- [ ] 数据主体请求流程
- [ ] 数据处理记录
- [ ] 与处理方签订的 DPA
```

保存为 markdown。可提供 DOCX 导出。

## 备注

- 这是一份模板——发布前应由法律顾问复核
- GDPR 与 CCPA 有不能靠近似处理的具体要求——在专家复核必不可少的地方要标出来
- 隐私政策应使用通俗语言，而不是法律行话
- 数据实践发生变化时就更新政策，而不是只在每年例行更新
