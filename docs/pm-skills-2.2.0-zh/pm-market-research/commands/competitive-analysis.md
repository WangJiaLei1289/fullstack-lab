# /competitive-analysis —— 竞争格局分析

研究并分析你所在的竞争格局。识别直接与间接竞品、绘制定位图，并找出差异化机会。

## 调用方式

```
/competitive-analysis AI 驱动的项目管理工具
/competitive-analysis 我们的产品 vs Notion、Asana 和 Monday.com
/competitive-analysis [上传竞品清单或市场简报]
```

## 工作流程

### 第 1 步：理解竞争背景

询问：
- 你的产品是什么？在哪个品类里竞争？
- 有没有指定要分析的竞品？还是由我识别？
- 用哪个视角？（功能对比、定位、定价、上市策略）
- 这份分析用来做什么？（战略、销售赋能、融资路演、产品路线图）

### 第 2 步：识别竞品

应用 **competitor-analysis** 技能：

- 识别 5 个直接竞品（同品类、同买方）
- 识别 2-3 个间接竞品（不同做法、同一待办任务）
- 如相关，标注新兴／颠覆性玩家
- 用网络搜索获取最新信息

### 第 3 步：分析每个竞品

对每个竞品：
- **定位**：他们如何描述自己、目标受众、核心信息
- **优势**：他们做得好、能赢的地方
- **劣势**：他们不足、常见抱怨的地方
- **定价**：模型与价位（若公开）
- **市场进展**：融资、团队规模、客户基础的信号
- **近期动作**：新功能、合作、转型

### 第 4 步：生成竞品分析

```
## 竞品分析：[你的产品／市场]

**日期**：[今天]
**分析对象**：[数量] 个竞品

### 市场概览
[2-3 句话：市场动态、趋势、走向]

### 竞争格局
| 竞品 | 品类 | 目标 | 定位 | 优势 | 劣势 |
|-----------|----------|--------|------------|----------|----------|

### 功能对比矩阵
| 能力 | 你的产品 | 竞品 A | 竞品 B | 竞品 C |
|-----------|-------------|-------------|-------------|-------------|

### 定位图
[用 2x2 矩阵展示关键维度上的竞争定位]

### 差异化机会
1. **[机会]** — [为什么可防御且有价值]
2. ...

### 竞争威胁
1. **[威胁]** — [要关注什么、建议如何应对]
2. ...

### 建议
- **加大投入**：[你的独有优势]
- **补齐差距**：[你缺的必备功能]
- **不理会**：[不值得回应的竞品动作]
```

保存为 markdown。

### 第 5 步：提供后续选项

- 「需要我为销售团队**做一份针对某个竞品的对战卡**吗？」
- 「要不要**制定一套与头部竞品差异化**的定位？」
- 「需要我**找出该补的功能缺口**并加入路线图吗？」

## 说明

- 竞品最新数据来自网络搜索——结果的新鲜度取决于可获得的来源
- 区分「必备门槛」（不做到就没法竞争）与「差异化点」（做到才能赢）
- 不要只列功能——要分析竞品*为什么*做这些选择
- 定价情报要注明是公开定价、按用量计费，还是需要联系销售
- 每季度更新这份分析——竞争格局变化很快
