# pm-market-research

面向产品经理的市场调研技能：用户画像、市场细分、情感分析与竞品分析。

## Skills (7) 技能

- **competitor-analysis** — 分析竞品，梳理其优势、劣势与差异化机会。
- **customer-journey-map** — 创建端到端客户旅程地图，包含阶段、触点、情绪、痛点与机会。
- **market-segments** — 识别 3-5 个潜在客户细分，并做人口统计、JTBD 与产品契合度分析。
- **market-sizing** — 用 TAM、SAM、SOM 结合自上而下与自下而上的方法估算市场规模。
- **sentiment-analysis** — 分析用户反馈数据，识别市场细分，给出情感得分、JTBD 与产品满意度洞察。
- **user-personas** — 基于研究数据创建精细的用户画像。
- **user-segmentation** — 根据反馈数据按行为、JTBD 与需求对用户做细分。

## Commands (3) 命令

- `/pm-market-research:analyze-feedback` — 大规模分析用户反馈——情感分析、主题提取与细分层面洞察。
- `/pm-market-research:competitive-analysis` — 分析竞争格局——识别竞品、对比优劣势、寻找差异化机会。
- `/pm-market-research:research-users` — 综合用户研究——建立用户画像、细分用户，并基于研究数据绘制客户旅程。
