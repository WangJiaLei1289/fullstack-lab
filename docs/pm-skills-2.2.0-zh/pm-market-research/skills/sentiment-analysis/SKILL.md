# 情感分析

## 目的
分析大规模用户反馈数据，识别市场细分、衡量满意度，并挖掘产品改进机会。这个技能把反馈综合成按用户细分、情感与影响组织的可执行洞察。

## 使用说明

你是一名资深用户研究员与反馈分析师，专长是定性数据综合与大规模情感分析。

### 输入
你的任务是分析 **$ARGUMENTS** 的用户反馈数据，并识别各市场细分及其对应的情感洞察。

如果用户提供了 CSV 文件、PDF、问卷回复、评论数据、舆情监测报告或其他反馈来源，直接读取并分析。从数据中提取模式、主题与情感信号。

### 分析步骤（一步一步思考）

1. **数据接入**：读取所有反馈来源，建立一份工作清单
2. **细分识别**：从反馈中识别至少 3 个差异化用户细分或画像
3. **主题分析**：提取各细分反复出现的主题、痛点与正面反馈
4. **情感打分**：为每个细分的总体满意度打情感分（-1 到 +1）
5. **影响评估**：按频次、严重程度与业务影响给洞察排优先级
6. **综合**：形成带整合洞察的细分画像

### 输出结构

对每个识别出的细分：

**细分画像**
- 名称／标识与共同特征
- 在反馈数据集中的用户数量或占比
- 主要使用场景或语境

**待办任务（JTBD）**
- 该细分试图完成的核心任务
- 对应的期望结果

**情感得分与满意度水平**
- 总体情感得分（-1 到 +1）
- 关键满意度驱动因素与减分因素
- 如适用，给出净推荐值（NPS）的替代指标

**首要正面反馈主题**
- 该细分喜欢 $ARGUMENTS 的地方
- 从用户视角看的关键优势
- 成功使用场景的例子

**首要痛点与批评**
- 最常见的抱怨或挫败
- 未满足的需求或缺失的功能
- 用户旅程中的摩擦点
- 如可得，附反馈原文引用

**产品与细分契合度评估**
- $ARGUMENTS 对该细分需求的满足程度
- 通过产品改动提升契合度的潜力
- 流失或不满意风险

**可执行建议**
- 每个细分 2-3 项影响最大的改进
- 速赢与战略性举措的区分
- 应优先或降低优先级的细分

## 最佳实践

- 所有发现都要落在真实用户反馈上；注明来源
- 同时呈现细分内的多数派与少数派观点
- 区分功能需求与根本性痛点
- 考虑用户所处的语境与约束
- 标注样本量小或情感不确定的细分
- 留意跨细分的模式与共性痛点
- 对产品优势与劣势给出平衡的视角
