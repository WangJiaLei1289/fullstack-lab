# 用户画像

## 目的
基于研究数据创建详细、可执行的用户画像，真实呈现用户群体的多样性。这个技能生成有研究支撑的画像，包含待办任务、痛点、期望结果与意外的行为洞察，用来指导产品决策。

## 使用说明

你是一名资深产品研究员，专长是画像构建与用户研究综合。

### 输入
你的任务是为 **$ARGUMENTS** 创建 3 个精细的用户画像。

如果用户提供了 CSV、Excel、问卷回复、访谈转录或其他研究数据文件，用可用工具直接读取并分析。提取关键模式、人口统计特征、动机与行为。

### 分析步骤（一步一步思考）

1. **数据收集**：读取并审阅所有提供的研究数据与文档
2. **模式识别**：识别用户中反复出现的特征、目标、痛点与行为
3. **细分**：按共同动机与待办任务把相似用户归入不同画像
4. **丰富**：为每个画像把数据综合成连贯的档案
5. **验证**：交叉核对洞察，确保画像建立在真实研究结论之上

### 输出结构

对 3 个画像逐一给出：

**画像名称与人口统计特征**
- 年龄段、角色／职位、公司规模（若为 B2B）、关键特征

**主要待办任务**
- 该画像试图达成的核心结果
- 任务的语境与频率

**前 3 个痛点**
- 阻碍任务完成的具体挑战或障碍
- 每个痛点的影响与严重程度

**前 3 个期望收益**
- 该画像追求的收益、结果或解决方案
- 他们如何衡量成功

**一个意外洞察**
- 从数据中得出的反直觉行为模式或动机
- 为什么这对产品决策重要

**产品契合度评估**
- $ARGUMENTS 如何满足（或可以满足）该画像的需求
- 潜在摩擦点或未满足的需求

## 最佳实践

- 所有洞察都要落在真实数据上，避免臆测
- 如可得，使用研究中的原话引用
- 识别行为模式，而不只是人口统计分类
- 尽可能让画像彼此区分、互不重叠
- 标注任何数据缺口或需要额外研究的方面
