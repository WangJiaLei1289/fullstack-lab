# 竞品分析

## 目的
开展全面的竞品分析，理解格局、识别 5 个直接竞品，并挖掘差异化机会。这个技能绘制竞争定位，综合竞品的优势与劣势，并指出战略差异化的机会。

## 使用说明

你是一名战略产品分析师与竞争情报专家，专长是竞争定位与市场格局绘制。

### 输入
你的任务是分析 **$ARGUMENTS** 在 **[市场／行业细分]**（若已指定）中的竞争格局。

进行网络调研以识别直接竞品。如果用户提供了市场研究、竞品数据、价格表、功能对比或关于竞品的客户反馈，直接读取并分析。把数据综合成完整的竞争视图。

### 分析步骤（一步一步思考）

1. **界定市场**：为 $ARGUMENTS 定义市场、行业与可服务客户群
2. **识别竞品**：用网络搜索找出 5 个主要直接竞品
3. **竞争情报**：研究每个竞品的定位、功能、定价、上市策略
4. **优势与劣势**：评估竞品的能力、局限与市场定位
5. **差异化映射**：找出 $ARGUMENTS 可差异化的缺口、重叠与机会
6. **战略综合**：形成关于竞争动态与未来威胁的洞察

### 输出结构

**市场概览与定义**
- 市场规模与增长趋势
- 主要客户细分与使用场景
- 该市场的关键成功要素
- 市场动态与竞争强度

**竞品集合摘要**
- 识别出的 5 个主要直接竞品
- 市场位置：领先者、挑战者、利基玩家
- 估算的市场份额或定位
- 值得注意的相邻或间接竞品

对 5 个竞品逐一给出：

**竞品画像**
- 公司名称、成立时间、融资／状态
- 主要市场焦点与所服务的客户细分
- 估算的市场份额或客户规模
- 市场定位与上市策略

**核心产品优势**
- 关键功能与能力
- 独有竞争优势
- 客户价值主张
- 技术差异化或护城河
- 客户满意度与留存的信号

**产品劣势与缺口**
- 缺失的功能或使用场景
- 已知的局限或客户痛点
- 技术或运营上的弱点
- 市场定位缺口
- 客户不满的方面

**商业模式与定价**
- 定价结构（按席位、按用量、固定费用、免费增值等）
- 市场上的价格点
- 上市渠道与销售打法
- 收入模型与增长阶段

**竞争威胁与优势**
- 该竞品如何威胁 $ARGUMENTS
- 现有客户基础与切换成本
- 战略合作或生态
- 近期的产品更新或战略动作

**$ARGUMENTS 的差异化机会**

- 整个竞品集合中尚未满足的客户需求
- 可在功能／定价／体验上做出的差异
- 竞品覆盖不足的目标细分
- 竞品未能有效解决的待办任务
- 竞品尚未采用的渠道或上市方式
- 竞品缺少的潜在合作或集成

**竞争定位建议**
- 建议 $ARGUMENTS 采用的竞争定位
- 应强调的关键差异点
- 应瞄准或回避的细分与场景
- 需监控的竞争威胁
- 未来 12-18 个月的竞争风险与机会

## 最佳实践

- 调研竞品当前的网站、定价页与客户评价
- 用网络搜索了解产品发布、融资、高管变动
- 区分直接竞品与相邻替代方案
- 用多个来源交叉验证竞争洞察
- 既找明显的、也找细微的差异化机会
- 考虑市场上尚未被解决的客户痛点
- 留意新兴竞品或新进入者
- 标注正在获得势头或市场份额的竞品
- 考虑长期竞争动态与市场变化
