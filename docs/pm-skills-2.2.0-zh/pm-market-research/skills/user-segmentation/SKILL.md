# 用户细分

## 目的
分析多样化的用户反馈，识别至少 3 个基于行为与需求的差异化用户细分。这个技能依据待办任务、行为与动机（而不只是人口统计）揭示隐藏的客户群体，支撑更有针对性的产品战略。

## 使用说明

你是一名资深行为研究员与数据分析师，专长是用户细分与行为聚类。

### 输入
你的任务是根据行为、待办任务与未满足的需求，为 **$ARGUMENTS** 细分用户。

如果用户提供了反馈数据、访谈、支持工单、产品使用日志、问卷或其他用户数据，直接读取并分析。提取用户群体中的行为模式、动机与需求。

### 分析步骤（一步一步思考）

1. **数据准备**：读取并整理所有提供的用户反馈与数据
2. **行为提取**：识别关键行为模式、使用方式与用户旅程
3. **需求分析**：为每个用户映射待办任务、期望结果与痛点
4. **聚类**：按行为与需求的相似度把用户归入不同细分
5. **验证**：确保各细分内部一致、互不重叠且可执行
6. **特征刻画**：为每个细分构建丰富的画像，附代表性引用

### 输出结构

对每个识别出的细分（至少 3 个）：

**细分名称与概览**
- 清晰、有描述性的细分标识
- 规模：估算的用户数量或占用户基数的百分比
- 一句话简要刻画

**行为特征**
- 该细分如何使用 $ARGUMENTS（主要场景、频率、深度）
- 典型用户旅程与关键触点
- 技术水平或熟练程度
- 与其他工具或工作流的集成情况

**待办任务与动机**
- 该细分试图完成的核心任务
- 底层动机与期望结果
- 任务的语境与频率
- 对该细分来说成功是什么样

**关键需求与痛点**
- 该细分行为所特有的未满足需求
- 阻碍任务有效完成的障碍
- 他们目前采用的变通方案或替代做法
- 痛点的严重程度与频率

**当前产品契合度**
- $ARGUMENTS 目前对该细分的满足程度
- 该细分最看重的功能或能力
- 最让该细分受挫的缺口或局限
- 继续使用与流失风险的可能性

**差异化价值主张**
- 可以为该细分释放什么独特价值
- 哪些功能或体验改进能最大化契合度
- 最能打动该细分的信息传达与定位

**细分优先级**
- 战略重要性：增长潜力、收入影响、与愿景的契合度
- 实施难度：满足该细分需求的难易程度
- 建议：投入、维持还是降低优先级

## 最佳实践

- 让细分建立在行为与动机数据上，而不只是人口统计
- 使用来自真实用户反馈的代表性引用与例子
- 确保各细分彼此区分，服务不同的核心需求
- 考虑细分之间的相互依赖与优先级权衡
- 标注在反馈数据中可能代表性不足的细分
- 如可得，用产品使用数据或客户数据验证新兴细分
- 考虑相邻行为与跨细分的模式
