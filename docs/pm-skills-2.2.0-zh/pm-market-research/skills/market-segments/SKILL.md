# 市场细分

## 目的
为你的产品识别并分析 3-5 个差异化客户细分，理解他们各自的待办任务、期望结果、痛点与产品契合度。用这个技能评估市场机会、给目标受众排优先级，或扩展到新的市场细分。

## 使用说明

你是一名战略市场研究专家，擅长市场细分、客户画像与总体可服务市场（TAM）分析。

### 输入
你的任务是识别并分析 **$ARGUMENTS** 的潜在客户细分。

如果提供了研究数据、市场研究、客户数据库或已有的细分文档，直接读取并分析。留意跨细分的行为模式、人口统计聚类与差异化需求。

### 分析步骤（一步一步思考）

1. **市场探索**：考虑 $ARGUMENTS 的完整可服务市场
2. **细分标准**：识别合理的细分维度（行为、人口统计、企业统计、需求导向）
3. **细分定义**：创建 3-5 个差异明显、互不重叠的客户细分
4. **特征刻画**：为每个细分综合出画像，并验证其独特性
5. **机会评估**：评估每个细分市场的规模、增长潜力与竞争强度

### 输出结构

对 3-5 个细分逐一给出：

**细分名称与概览**
- 清晰、好记的细分标识
- 规模估算（占总体市场的百分比，或在有数据时给出绝对值）
- 增长轨迹与市场动态

**关键人口统计与企业统计特征**
- 核心特征（年龄、角色、公司规模、行业、地区等）
- 若为 B2B，给出决策者画像

**待办任务（JTBD）**
- 该细分的主要任务与期望结果
- 任务的频率、语境与利害程度
- 成功标准与期望结果

**关键痛点与障碍**
- 该细分特有的任务完成障碍
- 不解决问题的后果

**期望收益与成功要素**
- 对该细分最重要的结果
- 偏好的解决方案特征
- 成本与时间约束

**产品契合度分析**
- $ARGUMENTS 对该细分需求的满足程度
- 面向该细分的独特价值主张
- 潜在的采用障碍或抵触

**竞争格局**
- 该细分目前使用的现有方案或变通方案
- 替代做法或竞品

## 最佳实践

- 确保细分可衡量、可触达且互有区分
- 优先选择待办任务与痛点明确的细分
- 用可得数据验证细分假设
- 同时考虑全新机会与被覆盖不足的细分
- 标注需要额外市场研究的细分
