## 利益相关方地图与沟通计划

把利益相关方映射到权力 × 利益网格上，并为每个群体制定有针对性的沟通计划。

### 背景

你正在帮助为 **$ARGUMENTS** 构建利益相关方地图。

如果用户提供文件（组织架构图、项目简报、团队名单），请先阅读。如果他们描述了产品或项目，请用这些背景推断可能的利益相关方。

### 使用说明

1. **识别利益相关方**：列出所有相关的个人与群体——高管、工程负责人、设计师、市场、销售、支持、法务、财务、外部合作伙伴以及最终用户。

2. **从两个维度给每位利益相关方分类**：
   - **权力（Power）**（高/低）：影响决策、资源或结果的能力
   - **利益（Interest）**（高/低）：项目对他们的直接影响程度，或他们的参与程度

3. **把利益相关方放入权力 × 利益网格**：

   | | 高利益 | 低利益 |
   |---|---|---|
   | **高权力** | **重点管理**——定期一对一、让其参与决策、尽早征求其意见 | **保持满意**——定期同步、仅升级关键问题 |
   | **低权力** | **保持知情**——定期同步进展、邀请参加演示、收集反馈 | **监控**——轻量同步、按需提供 |

4. **为每个象限**建议：
   - 沟通频率（每天、每周、每两周、每月）
   - 沟通形式（一对一、邮件、Slack、会议、仪表盘）
   - 关键信息与表达框架
   - 如果忽视该利益相关方可能带来的风险

5. **创建沟通计划表**：

   | 利益相关方 | 角色 | 权力 | 利益 | 策略 | 频率 | 渠道 | 关键信息 |
   |---|---|---|---|---|---|---|---|

6. **标出潜在冲突**：找出利益相互竞争的各方，并提出对齐策略。

逐步思考。把利益相关方地图保存为 markdown 文档。
