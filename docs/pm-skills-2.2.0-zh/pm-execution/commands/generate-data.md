# /generate-data —— 测试数据生成器

为开发、测试、演示或原型制作生成逼真的假数据集，按你偏好的格式输出可直接使用的文件。

## 调用方式

```
/generate-data 1000 users with names, emails, plan tier, signup date, and activity score
/generate-data E-commerce orders dataset: products, customers, timestamps, amounts
/generate-data Sample data matching this schema: [paste table definition]
```

## 工作流程

### 第 1 步：定义数据集

明确以下问题：
- 涉及哪些实体？（用户、订单、事件、产品等）
- 需要哪些列？（含数据类型和约束）
- 需要多少行？
- 表之间是否存在关系？
- 是否有特定的分布要求？（例如「80% 的用户应处于免费套餐」）
- 是否有需要遵守的现实约束？（邮箱应唯一，日期应按时间顺序排列）

### 第 2 步：生成数据

应用 **dummy-dataset** 技能：

- 编写一个用于生成数据集的 Python 脚本
- 使用看起来真实的数据（而非随机字符串）：像样的姓名、有效的邮箱格式、看起来合理的日期
- 遵守约束：唯一 ID、外键关系、时间先后顺序
- 按指定的分布生成数据
- 执行脚本并产出输出文件

### 第 3 步：交付

按要求的格式输出（或主动询问）：
- **CSV**：最常见，各处都能用
- **JSON**：用于 API 测试或前端开发
- **SQL INSERT**：用于填充测试数据库
- **Python 脚本**：便于可复现地生成（用户可以调整参数并重新运行）

```
## 生成的数据集：[描述]

**行数**：[数量]
**列**：[列表]
**格式**：[CSV / JSON / SQL / Python]

### 表结构
| 列 | 类型 | 约束 | 分布 |
|--------|------|-----------|-------------|

### 示例（前 5 行）
[数据预览]

### 文件
- [数据文件]
- [生成脚本（如适用）]
```

将数据文件和生成脚本保存到用户的工作区。

### 第 4 步：提供后续动作

- 「要我 **增加更多列** 或 **扩大数据集规模** 吗？」
- 「要我 **创建相关联的表**（例如这些用户的订单）吗？」
- 「要我 **编写使用这份数据的测试场景** 吗？」
- 「要我 **创建 SQL 查询** 来分析这个数据集吗？」

## 说明

- 始终提供生成脚本，方便用户用不同参数重新生成
- 对于演示数据集，让数据讲一个故事（例如季节性趋势、留存问题、重度用户群体）
- 遵守现实的基数关系：1000 个用户不会分布在 1000 个不同城市
- 对财务数据，使用逼真的价格分布 — 而非均匀随机
- 绝不包含真实的个人数据 — 所有姓名、邮箱和标识符都必须是虚构的
