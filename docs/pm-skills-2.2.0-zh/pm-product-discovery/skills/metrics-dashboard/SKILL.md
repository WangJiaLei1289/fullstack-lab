## 产品指标看板

设计一套完整的产品指标看板，包含合适的指标、可视化和告警阈值。

### 背景

你正在为 **$ARGUMENTS** 设计指标看板。

如果用户提供了文件（现有看板、分析数据、OKR 或战略文档），先读取它们。

### 领域背景

**指标、KPI 与北极星指标的区别**：指标 = 所有可度量的事物。KPI = 少数几个长期追踪的关键量化指标。北极星指标 = 一个以客户为中心、能先行预示业务成败的关键 KPI。

**好指标的 4 条标准**（Ben Yoskovitz《Lean Analytics》）：(1) 可理解 —— 能形成共同语言。(2) 可比较 —— 看趋势，而不是看快照。(3) 用比率或速率 —— 比绝对数更能说明问题。(4) 能改变行为 —— 黄金法则：「如果一个指标不会改变你的行为，它就是个坏指标。」

**8 种指标类型**：虚荣指标 vs 可行动指标（只有可行动指标才会改变行为）、定性 vs 定量（WHAT 与 WHY —— 两者都要；永远不要停止与客户交谈）、探索 vs 汇报（主动探索数据以发现意外洞察）、滞后 vs 先行（先行指标能带来更快的反馈循环，例如客户投诉可以预测流失）。

**5 个行动步骤**：(1) 按 4 条好指标标准审计现有指标。(2) 更新看板——确保所有关键指标都是好指标。(3) 找出虚荣指标——谨慎使用。(4) 区分先行指标与滞后指标。(5) 选一个问题，深入挖掘数据。

案例与更多细节见 Ben Yoskovitz 的 [你在追踪正确的指标吗？](https://www.productcompass.pm/p/are-you-tracking-the-right-metrics)

### 使用说明

1. **确定指标体系** —— 把指标分层组织：

   **北极星指标**：最能代表核心价值交付的那一个指标

   **输入指标**（3-5 个）：驱动北极星指标的杠杆

   **健康指标**：确保产品整体健康的护栏

   **业务指标**：营收、成本和单位经济模型

2. **为每个指标定义**：

   | 指标 | 定义 | 数据来源 | 可视化 | 目标 | 告警阈值 |
   |---|---|---|---|---|---|
   | [名称] | [精确计算方式：分子/分母、时间窗口] | [数据来自哪里] | [折线图 / 柱状图 / 数字卡 / 漏斗] | [目标值] | [何时触发告警] |

3. **设计看板布局**：

   ```
   ┌─────────────────────────────────────────────┐
   │  NORTH STAR：[指标] —— [当前值]             │
   │  趋势：[↑/↓ 较上期 X%]                      │
   ├──────────────────────┬──────────────────────┤
   │  输入指标 1          │  输入指标 2          │
   │  [迷你趋势图]        │  [迷你趋势图]        │
   ├──────────────────────┼──────────────────────┤
   │  输入指标 3          │  输入指标 4          │
   │  [迷你趋势图]        │  [迷你趋势图]        │
   ├──────────────────────┴──────────────────────┤
   │  健康：[延迟] [错误率] [NPS]                │
   ├─────────────────────────────────────────────┤
   │  业务：[MRR] [CAC] [LTV] [流失率]           │
   └─────────────────────────────────────────────┘
   ```

4. **设定复盘节奏**：
   - **每天**：运营健康度（错误、延迟、关键链路）
   - **每周**：输入指标与参与度趋势
   - **每月**：北极星指标、业务指标、OKR 进展
   - **每季度**：战略复盘与指标校准

5. **定义告警**：
   - 哪些阈值会触发排查？
   - 通知谁、通过什么渠道？
   - 预期的响应时间是多少？

6. **根据用户的情况推荐工具**：
   - Amplitude、Mixpanel、PostHog 用于产品分析
   - Looker、Metabase、Mode 用于基于 SQL 的看板
   - Datadog、Grafana 用于运营健康度

逐步思考。把看板规格说明保存为 markdown 文档。
