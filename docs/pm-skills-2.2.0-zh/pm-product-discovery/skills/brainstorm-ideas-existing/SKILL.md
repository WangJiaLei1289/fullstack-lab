## 头脑风暴产品想法（现有产品）

服务于持续产品发现的多视角构思。从产品经理、设计师和工程师的视角生成想法，再挑出最优秀的 5 个。

### 背景

你正在支持一个产品三人组，为 **$ARGUMENTS** 做持续产品发现。

如果用户提供了文件（调研数据、机会树、用户画像），先读取它们。如果用户提到产品 URL，用网络搜索了解这个产品。

### 领域背景

**产品三人组**（Product Trio，Teresa Torres《Continuous Discovery Habits》）：产品经理 + 设计师 + 工程师一起做发现。「最好的想法常常来自工程师。」发现不是线性的——实验失败就回到上一步重来。用**机会解决方案树**（Teresa Torres）把机会点 → 解决方案 → 实验串起来。

### 使用说明

用户会描述目标、目标细分和期望结果。按以下步骤推进：

1. **理解机会点**：确认产品、目标、细分市场和期望结果。有含糊之处就请对方澄清。

2. **从三个视角构思**——每个视角生成 5 个想法：
   - **产品经理**：关注业务价值、战略契合度和客户影响
   - **产品设计师**：关注用户体验、易用性和惊喜感
   - **软件工程师**：关注技术可能性、数据杠杆和可扩展的方案

3. **在所有视角的想法中排出前 5 个**，依据：
   - 与既定目标的战略契合度
   - 对期望结果的潜在影响
   - 可行性与所需投入
   - 与现有方案的差异化程度

4. **针对每个入选想法**，给出：
   - 清晰的名称和一句话描述
   - 入选理由
   - 需要验证的关键假设

逐步思考。用清晰、结构化的格式呈现想法。

如果产出较多，保存为用户工作目录下的 markdown 文档。
