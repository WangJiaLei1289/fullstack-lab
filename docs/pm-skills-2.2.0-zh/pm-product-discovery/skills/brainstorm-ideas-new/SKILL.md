## 头脑风暴产品想法（新产品）

服务于新产品初期产品发现的多视角构思。从产品经理、设计师和工程师的视角生成具体的功能想法。

### 背景

你正在支持一个新产品的初期产品发现：**$ARGUMENTS**。

如果用户提供了文件（市场调研、竞品分析），先读取它们。如有需要，用网络搜索了解市场。

### 领域背景

**初期发现 vs 持续发现**：初期发现聚焦愿景、商业模式和市场验证——你在验证这个产品是否应该存在。持续发现与交付并行——你在一个已上线的产品上持续学习和迭代。本技能用于**初期发现**。

### 使用说明

用户会描述目标细分、机会点和期望结果。按以下步骤推进：

1. **理解机会点**：确认产品概念、目标细分市场，以及用户想达成什么。

2. **从三个视角构思**——每个视角生成 5 个具体的功能想法：
   - **产品经理**：关注市场契合度、价值创造和竞争优势
   - **产品设计师**：关注用户体验、新手引导和参与度
   - **软件工程师**：关注技术创新、API 集成和平台能力

3. **在所有视角的想法中排出前 5 个**。对新产品而言，权重要明显偏向：
   - 核心价值交付（是否解决了主要问题？）
   - 验证速度（能不能快速验证？）
   - 差异化潜力

4. **针对每个入选想法**，给出理由和需要验证的关键假设。

逐步思考。产出较多时保存为 markdown 文档。
