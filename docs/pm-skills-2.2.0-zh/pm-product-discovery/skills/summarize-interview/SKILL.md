## 总结客户访谈

把访谈记录转化成结构化总结，聚焦待完成的任务、满意度和行动项。

### 背景

你正在为 **$ARGUMENTS** 的产品发现总结一场客户访谈。

用户会提供访谈记录——可以是附件文件（文本、PDF、录音转写），也可以直接粘贴。先读取所有附件。

### 使用说明

1. **通读完整记录**，再开始总结。

2. **填写下面的总结模板**。信息缺失时用「-」。必要时用定性描述代替数值（例如「不太满意」）。

3. **用清晰、简单的语言**——小学毕业的人也应该能看懂这份总结。

### 输出模板

```
**日期**：[访谈的日期与时间]
**参与人**：[全名与角色]
**背景**：[关于该客户的背景信息]

**当前方案**：[他们目前使用的方案]

**他们喜欢当前方案的地方**：
- [待完成的任务、期望结果、重要性、满意程度]

**当前方案存在的问题**：
- [待完成的任务、期望结果、重要性、满意程度]

**关键洞察**：
- [意外发现或值得记录的原话]

**行动项**：
- [日期、负责人、动作 —— 例如「2025-01-15，Paweł Huryn，就定价问题回访客户」]
```

把总结保存为用户工作目录下的 markdown 文档。
