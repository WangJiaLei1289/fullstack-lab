## 设计精益创业实验（新产品）

创建 XYZ 假设，并设计预原型（pretotype）实验，用最小投入验证新产品概念。

### 背景

你正在用精益创业方法论帮助验证一个新产品概念：**$ARGUMENTS**。

如果用户提供了文件（市场调研、落地页设计稿），先读取它们。

### 使用说明

1. **创建一个 XYZ 假设**，形式为：「至少有 X% 的 Y 会做 Z」
   - **X%**：预期会参与的目标市场比例
   - **Y**：具体的目标市场（例如「中大型豪华轿车买家」）
   - **Z**：他们会如何与产品互动

2. **建议 2-3 个预原型实验**，用最小投入验证该假设。可以考虑：
   - **落地页**：通过注册量或点击量测试兴趣
   - **讲解视频**：通过参与度指标测试理解度与吸引力
   - **邮件营销**：通过回复率和点击率测试需求
   - **预售 / 候补名单**：通过押上真实承诺测试付费意愿
   - **管家式 / 手工 MVP**：人工交付服务来测试价值

3. **关键原则**（Alberto Savoia，《The Right It》）：
   - **押上筹码（Skin-in-the-Game）**：验证付费意愿，而不只是兴趣。真实的承诺（时间、金钱、声誉）才是唯一可靠的信号。
   - **自有数据（YODA）**：通过实验收集你自己的数据，而不是依赖他人数据（ODP），例如市场报告或类比。「你这款产品的市场，并不关心别人那款产品的市场。」
   - 度量真实行为，而不是用户的观点

4. **针对每个实验**，写明所验证的假设、方法、指标和成功阈值。

逐步思考。内容较多时保存为 markdown。
