# pm-product-discovery

面向产品经理的产品发现技能：构思、实验、假设验证、功能排优先级，以及客户访谈总结。

## Skills (13)

- **analyze-feature-requests** —— 按主题、战略契合度、影响、投入和风险，分析一组功能需求并排定优先级。
- **brainstorm-experiments-existing** —— 为现有产品设计实验，用来验证各项假设。
- **brainstorm-experiments-new** —— 为新产品设计精益创业式实验（预原型，pretotype）。
- **brainstorm-ideas-existing** —— 用多视角构思（产品经理、设计师、工程师）为现有产品头脑风暴产品想法。
- **brainstorm-ideas-new** —— 在初期发现阶段为新产品头脑风暴功能想法。
- **identify-assumptions-existing** —— 针对现有产品中的功能想法，从价值、可用性、商业可行性和技术可行性四个维度识别高风险假设。
- **identify-assumptions-new** —— 针对新产品想法，跨 8 个风险类别（包括上市策略、战略和团队）识别高风险假设。
- **interview-script** —— 编写结构化的客户访谈提纲，包含 JTBD 追问问题、暖场、核心探索和收尾环节。
- **metrics-dashboard** —— 定义并设计产品指标看板，涵盖关键指标、数据来源、可视化类型和告警阈值。
- **opportunity-solution-tree** —— 构建机会解决方案树（OST）来组织产品发现——把期望结果映射到机会点、解决方案和实验。
- **prioritize-assumptions** —— 用「影响 × 风险」矩阵为假设排优先级，并为每项假设建议相应实验。
- **prioritize-features** —— 基于影响、投入、风险和战略契合度，为一组待办的功能想法排优先级。
- **summarize-interview** —— 把客户访谈记录整理成结构化模板，包含 JTBD、满意度信号和行动项。

## Commands (5)

- `/pm-product-discovery:brainstorm` —— 从产品经理、设计师和工程师三个视角头脑风暴产品想法或实验——适用于现有产品或新产品。
- `/pm-product-discovery:discover` —— 跑完一整轮产品发现——从构思、假设映射一直到实验设计。
- `/pm-product-discovery:interview` —— 准备客户访谈提纲，或把访谈记录整理成结构化洞察。
- `/pm-product-discovery:setup-metrics` —— 设计产品指标看板，包含北极星指标、输入指标、健康指标和告警阈值。
- `/pm-product-discovery:triage-requests` —— 分析、归类并为一组来自客户或利益相关方的功能需求排定优先级。
