# 理想客户画像

## 概览
从调研与问卷数据中识别你的理想客户画像（ICP）。本技能综合客户调研，定义最有可能从你的产品中获得价值、留存并扩张的客户。

## 适用场景
- 根据产品市场契合度调研数据定义 ICP
- 瞄准高价值客户细分
- 分析客户成功与扩张模式
- 排定销售与市场工作的优先级
- 评估新客户机会的契合度
- 优化目标市场定义

## ICP 框架的组成部分

### 人口特征
从公司特征与个人角度看，他们是谁？
- 公司规模（员工数、收入）
- 行业或垂直领域
- 地理位置
- 职位与所属部门
- 在岗位上工作年限
- 教育背景
- 组织结构与汇报关系

### 行为
他们如何工作、如何做决策？
- 如何发现并评估解决方案
- 采购流程与决策时间线
- 技术素养与产品采用速度
- 协作风格（个人决策还是委员会决策）
- 变革管理与采用风格
- 工具切换频率
- 社区参与与同伴影响

### 要完成的任务（JTBD）
他们想要达成什么？
- 他们试图达成的主要任务/目标
- 支撑主要任务的次要任务
- 情感任务（他们希望有什么感受）
- 社交任务（地位与形象）
- 他们希望避免或消除的任务
- 每项任务的频率与重要性
- 完成任务的成功衡量标准

### 需求与痛点
你的产品解决什么问题？
- 他们经历的具体痛点
- 当前的变通方案与局限
- 对生产力或结果的影响
- 问题带来的成本或时间负担
- 情绪上的挫败程度
- 解决问题的障碍
- 可用于解决问题的预算
- 相互竞争的优先事项

## 工作原理

### 第 1 步：收集客户数据
收集关于现有与潜在客户的调研：
- 产品市场契合度问卷回答
- 客户访谈逐字稿
- 试用或 freemium 用户行为数据
- 客户反馈与支持工单
- 流失分析与客户生命周期数据
- 销售侧的赢单/输单分析
- 竞品客户分析

### 第 2 步：按价值分群
识别客户群及其价值：
- LTV（生命周期价值）最高的客户
- 实现价值最快的客户
- 流失率最低的客户
- 扩张/增购最多的客户
- 最热情/最投入的客户
- 最适合做参考案例/客户故事的客户
- 与产品愿景最契合的客户

### 第 3 步：刻画人口特征
提炼公司特征模式：
- 常见的公司规模（员工数、收入）
- 行业垂直领域与子领域
- 地理集中区域
- 典型部门与汇报结构
- 预算持有者与可用预算
- 公司阶段（初创、成长、成熟企业）
- 公司文化特征

### 第 4 步：识别行为
梳理决策与采用模式：
- 他们如何发现你的产品（渠道）
- 评估流程与时间线
- 决策中的关键利益相关方
- 销售过程中的障碍
- 产品采用的速度与广度
- 团队在新手引导中的参与
- 功能使用频率
- 支持与服务需求

### 第 5 步：定义 JTBD
清楚表达他们想要达成什么：
- 主要任务/目标（功能性任务）
- 情感维度（他们希望有什么感受）
- 社交维度（对团队与利益相关方的影响）
- 成功指标（他们如何衡量成功）
- 背景与约束（何时、何地、与谁）
- 相互竞争的任务与优先事项
- 各项任务的重要性排序

### 第 6 步：记录痛点与需求
综合具体的问题领域：
- 之前的状态（当前处境与挫败感）
- 期望之后的状态（理想的未来状态）
- 差距大小与影响量化
- 问题的情感维度
- 阻碍解决方案的资源约束
- 怀疑或犹豫
- 解决方案的成功标准

## 输入格式
使用 $ARGUMENTS 传入：
- 调研数据（问卷、访谈、逐字稿）
- 客户成功/指标数据
- 产品使用分析
- 销售活动与赢单/输单数据
- 现有客户数据库
- 竞争情报

## 输出
一份完整的 ICP 定义，包含：
- 公司特征画像（公司规模、行业、地点）
- 行为画像（采购模式、采用风格）
- 完整的 JTBD 映射（功能性、情感、社交任务）
- 前 5-7 个痛点与具体需求
- 量化的影响指标（问题的成本、解决方案的价值）
- 决策流程与关键利益相关方
- 典型客户旅程与时间线
- 对 GTM 的启示与信息传达
- 不合格标准（谁不是合适客户）
- ICP 内的高价值细分（理想中的理想客户）

## 框架
基于 Clayton Christensen 的 Jobs to Be Done 理论与客户画像方法论。结合行为数据与动机洞察，定义可落地的客户画像。

## 提示
- 定量与定性数据结合使用
- 访谈 10+ 位高价值客户以识别模式
- 寻找不那么明显的人口特征模式（离群点也可能是高价值的）
- 同时定义理想 ICP 与可接受的次级细分
- 随着客户数据积累，每季度重新审视 ICP
- 用 ICP 评估所有新的销售机会
- 在整个组织（市场、销售、产品）共享 ICP
- 记住：ICP 应当驱动聚焦，而不是排除其他所有人
