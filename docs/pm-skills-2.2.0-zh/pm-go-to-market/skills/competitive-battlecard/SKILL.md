## 竞争对战卡

为针对特定竞品的使用场景，创建一份简洁、可直接用于销售的对战卡。

### 背景

你正在为 **$ARGUMENTS** 创建竞争对战卡。

使用网络搜索调研竞品当前的产品、定价、定位与近期变化。如果用户提供文件（功能清单、赢单/输单数据、销售通话记录），请先阅读。

### 使用说明

1. **调研竞品**（使用网络搜索）：
   - 当前产品线与功能
   - 定价档位与模型
   - 目标市场与定位
   - 近期产品发布或变化
   - 已知优势与弱点
   - 客户评价与情绪（G2、Capterra、Reddit）

2. **创建对战卡**，包含以下部分：

   ### 公司概览
   - 成立时间、总部、融资/收入（如公开）
   - 目标市场与 ICP
   - 用一句话概括其定位

   ### 快速对比

   | 能力 | 我们 | 他们 | 胜出方 |
   |---|---|---|---|
   | [功能领域 1] | [我们的做法] | [他们的做法] | [我们/他们/平手] |
   | [功能领域 2] | ... | ... | ... |
   | 定价 | ... | ... | ... |
   | 支持 | ... | ... | ... |

   ### 我们的优势
   - [优势 1]：[佐证或客户原话]
   - [优势 2]：[他们缺少的具体能力]
   - [优势 3]：[更好的做法及理由]

   ### 他们的优势
   - [他们的优势 1]：[我们的反向定位]
   - [他们的优势 2]：[我们如何弥补这一差距]

   ### 常见异议与回应

   | 潜在客户说 | 回应方式 |
   |---|---|
   | 「竞品 X 有 [功能]」 | 「[我们的替代做法，以及为什么对他们更好]」 |
   | 「他们更便宜」 | 「[价值框定：总拥有成本、ROI、隐性成本]」 |
   | 「他们更成熟」 | 「[我们的优势：速度、创新、聚焦、支持]」 |

   ### 要埋下的「地雷问题」
   向潜在客户提出的、能凸显竞品弱点的问题：
   - 「[我们擅长、而对方不擅长的领域] 对你们团队有多重要？」
   - 「你们评估过 [他们缺少的具体能力] 吗？」

   ### 赢单/输单模式
   - 我们通常在以下情况赢单：[模式]
   - 我们通常在以下情况输单：[模式]
   - 竞争型交易中的关键差异点：[决定天平的因素]

3. **保持可快速浏览**：销售代表需要在通话中查阅。使用表格、加粗文本与简短要点。

保存为 markdown。便于打印或在 Notion/Confluence 中分享。
