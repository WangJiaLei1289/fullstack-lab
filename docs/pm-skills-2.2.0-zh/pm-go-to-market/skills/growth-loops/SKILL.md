# 增长循环

## 概览
识别并设计能带来可持续增长势头的增长循环（飞轮）。本技能评估五种经过验证的增长循环机制，以降低对付费获客的依赖，构建产品驱动增长。

## 适用场景
- 为产品设计增长机制
- 构建可持续的病毒式或推荐式增长
- 降低对付费获客的依赖
- 分析竞品的增长战略
- 为产品驱动增长优化产品

## 5 种增长循环类型

### 1. 病毒循环（Viral Loop）
用户创造的产品内容被分享到外部平台，从而把新用户带回产品。
- **机制**：用户在产品内创作内容 → 分享到社交/外部平台 → 新用户发现并注册
- **示例**：Figma 设计以链接形式分享、Loom 视频在邮件中分享
- **优势**：如果内容本身易于分享，用户获取呈指数级
- **挑战**：需要高度可分享的产出，以及强烈的分享动机

### 2. 使用循环（Usage Loop）
用户在产品内创作内容或价值，然后分享出去，从而带来新用户或促使用户回访。
- **机制**：用户创作 → 分享作品 → 他人消费 → 成为活跃用户
- **示例**：Twitter 推文串、Medium 文章、公开分享的 Notion 模板
- **优势**：增长与产品使用、网络效应直接挂钩
- **挑战**：要求内容创作的摩擦极低

### 3. 协作循环（Collaboration Loop）
用户邀请同事在产品内共同创作或协作，从而在组织内部扩大用户基础。
- **机制**：用户创作 → 邀请同事协作 → 同事体会到产品价值
- **示例**：Google Docs 邀请、Figma 团队项目、Slack 频道
- **优势**：深入组织渗透，留存率高
- **挑战**：最适合协作型/团队型产品

### 4. 用户生成循环（User-Generated Loop）
用户通过他人的创作发现新内容或新功能，然后创作并分享自己的内容。
- **机制**：用户发现内容 → 创作类似内容 → 分享作品 → 他人发现
- **示例**：TikTok、Pinterest、YouTube 的热门趋势带动创作者参与
- **优势**：形成内容飞轮与网络效应
- **挑战**：需要达到高质量内容的关键规模才能持续

### 5. 推荐循环（Referral Loop）
用户通过奖励、激励或社交认可，邀请其他潜在用户。
- **机制**：用户推荐 → 被推荐者加入 → 推荐者获得奖励 → 分享更多推荐
- **示例**：Dropbox 推荐奖励、Uber 乘客推荐、PayPal 注册奖励
- **优势**：直接激励获客；ROI 易于衡量
- **挑战**：需要有价值的激励，又不能侵蚀单位经济模型

## 工作原理

### 第 1 步：定义产品价值
厘清用户能体验到的核心价值：
- 用户在你的产品中的主要动作
- 每次用户动作创造的价值
- 是否存在网络效应
- 体验中的摩擦点

### 第 2 步：评估循环适配度
评估哪些增长循环与你的产品契合：
- 产品类型（协作型、内容型、工具型等）
- 目标用户行为与分享习惯
- 已经存在的网络效应
- 现有用户基础与参与度

### 第 3 步：设计循环机制
设计具体的循环实施方案：
- 触发分享或邀请的触发器
- 参与激励（内在或外在）
- 分享机制的便捷程度
- 从邀请到激活的转化率
- 每位用户重复循环的频率

### 第 4 步：计算循环系数
估算增长速度：
- 每个周期每位用户的邀请/分享数
- 邀请转化为新用户的转化率
- 每个周期的净新增用户
- 每次循环迭代所需时间

### 第 5 步：构建循环
先实现杠杆效应最高的循环：
- 从最自然的循环开始
- 优化信息传达与摩擦
- 衡量循环指标与转化率
- 让效果随时间复利

## 输入格式
使用 $ARGUMENTS 传入：
- 产品描述与主要用户动作
- 目标用户的人口特征与行为
- 现有的分享/协作功能
- 当前增长渠道与指标
- 约束或机会

## 输出
一份增长循环分析，包含：
- 针对你产品的 5 种循环类型的排序评估
- 推荐的主增长循环及实施计划
- 后续可叠加的次级循环
- 关键指标与衡量框架
- 30-60-90 天实施路线图
- 潜在循环系数与增长预测

## 框架
基于 Ognjen Bošković 的增长循环研究。聚焦通过内建的、产品原生的分享与协作机制，实现复利式的用户获取。

## 提示
- 先从一个循环开始，掌握后再增加复杂度
- 病毒循环复利最快，但建设需要时间
- 协作循环带来最强的留存与 LTV
- 优化阶段每周衡量循环健康度
- 达到规模后组合多个循环以获得乘数效应
