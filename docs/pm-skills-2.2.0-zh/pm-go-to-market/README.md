# pm-go-to-market

面向产品经理的上市（GTM）技能：GTM 战略、增长循环、GTM 打法、滩头细分市场与理想客户画像。

## Skills (6)

- **beachhead-segment** —— 为产品发布识别第一个滩头细分市场。
- **competitive-battlecard** —— 创建可直接用于销售的竞争对战卡，将你的产品与特定竞品进行对比。
- **growth-loops** —— 识别增长循环（飞轮），实现可持续的用户增长。
- **gtm-motions** —— 识别最合适的 GTM 打法与工具。
- **gtm-strategy** —— 为产品发布创建 GTM 战略，涵盖营销渠道、信息传达、成功指标与发布计划。
- **ideal-customer-profile** —— 从调研数据中识别理想客户画像（ICP），包含人口特征、行为、JTBD 与需求。

## Commands (3)

- `/pm-go-to-market:battlecard` —— 创建可直接用于销售的竞争对战卡——定位、功能对比、异议处理与取胜策略。
- `/pm-go-to-market:growth-strategy` —— 设计可持续的增长机制——面向产品驱动与销售驱动策略的增长循环与 GTM 打法。
- `/pm-go-to-market:plan-launch` —— 创建完整的 GTM 战略——滩头细分市场、ICP、信息传达、渠道与发布计划。
