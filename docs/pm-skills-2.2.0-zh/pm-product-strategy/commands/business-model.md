# /business-model —— 商业模式探索

使用四个互补的框架来构建和分析商业模式。你可以选择其中一个，也可以全部运行以得到完整图景。

## 调用方式

```
/business-model lean Marketplace connecting freelance PMs with startups
/business-model full Enterprise analytics platform
/business-model startup AI writing tool for non-native English speakers
/business-model value-prop SaaS onboarding tool
/business-model all SaaS onboarding tool        # runs all four
/business-model                                   # asks what you need
```

## 模式说明

---

### 精益画布模式

适用场景：早期想法、创业公司、新产品线。

应用 **lean-canvas** 技能，产出一份完整的精益画布：

```
## 精益画布：[产品]

| 问题（前 3 个） | 解决方案 | 独特价值主张 |
|-----------------|----------|------------------------|
| 1. [问题]    | [针对每个问题的解决方案] | [一句清晰的信息] |
| 2. [问题]    |          |                        |
| 3. [问题]    |          |                        |

| 关键指标 | 不公平优势 |
|------------|-----------------|
| [你衡量的内容] | [别人无法复制的东西] |

| 渠道 | 客户细分 |
|---------|------------------|
| [如何触达他们] | [是谁，优先早期采用者] |

| 成本结构 | 收入来源 |
|---------------|----------------|
| [固定成本 + 可变成本] | [如何赚钱] |

### 风险最高的假设
[要让这套模式成立，必须为真的是什么——按风险排序]

### 待运行的实验
[如何用低成本方式验证风险最高的假设]
```

---

### 完整商业模式画布模式

适用场景：成熟产品、战略规划、面向投资人的材料。

应用 **business-model** 技能，产出全部 9 个构造块：

```
## 商业模式画布：[产品]

| 关键合作伙伴 | 关键业务 | 价值主张 | 客户关系 | 客户细分 |
|-------------|---------------|-------------------|----------------------|------------------|
| [谁在帮你] | [核心动作] | [客户为什么选择你] | [你如何互动] | [你服务谁] |

| 关键资源 | | 渠道 | |
|-------------|---|---------|---|
| [你需要什么] | | [你如何交付] | |

| 成本结构 | 收入来源 |
|---------------|----------------|
| [你的成本] | [你的收入] |

### 分析
[这套模式的优势与劣势]
[各部分如何相互强化]
[脆弱点与依赖项]
```

### 创业画布模式

适用场景：需要在同一份产物里同时得到战略与商业模式的新产品和创业公司。对新产品而言，它比精益画布和商业模式画布更值得推荐。

应用 **startup-canvas** 技能，产出一份包含 9 个战略部分 + 商业模式的创业画布：

```
## 创业画布：[产品]

### 第 1 部分：产品战略

| 愿景 | 细分市场 | 相对成本 |
|--------|----------------|---------------|
| [鼓舞人心的为什么] | [JTBD，第一个细分市场] | [低成本还是独特价值] |

| 价值主张 | 取舍 | 关键指标 |
|------------------|-----------|------------|
| [之前是什么 → 如何做 → 之后是什么 → 替代方案] | [你不会做什么] | [北极星指标 + OMTM] |

| 增长 | 能力 | 不能/不会 |
|--------|-------------|------------|
| [PLG 还是销售驱动，渠道] | [自建还是合作] | [竞品为什么无法复制] |

### 第 2 部分：商业模式

| 成本结构 | 收入来源 |
|---------------|----------------|
| [固定成本 + 可变成本，如何随规模变化] | [定价模型、各渠道收入] |

### 战略一致性检查
[所有要素是否相互强化？]

### 风险最高的假设
[必须为真的是什么——以及如何验证]
```

---

### 价值主张模式

适用场景：打磨信息传达、理解用户价值、分析产品市场契合。

应用 **value-proposition** 技能，产出以 JTBD 为框架的价值主张：

```
## 价值主张：[产品]

### 面向 [细分市场]：
1. **Who（是谁）**：[目标用户画像]
2. **Why（为什么）**：[他们想完成的任务]
3. **What Before（之前是什么）**：[他们当前痛苦的现实]
4. **How（如何做）**：[你的解决方案思路]
5. **What After（之后是什么）**：[他们改善后的现实]
6. **Alternatives（替代方案）**：[没有你他们会用什么，以及你为什么更好]

### 价值主张陈述
[一句话：对于 [需要什么] 的 [谁]，[产品] 是一款 [品类]，能够 [带来什么收益]。不同于 [替代方案]，我们 [差异点]。]
```

---

### 全部模式

运行全部四个框架，并额外增加一节综合，对比各框架得出的洞察。

## 工作流程（所有模式）

### 第 1 步：收集背景

需要了解：
- 产品或业务想法是什么？
- 处于哪个阶段？（想法、已验证、规模化）
- 是否有需要改进的现有商业模式？
- 目标客户是谁？

### 第 2 步：生成所选框架

按上文说明应用相应的技能。

### 第 3 步：保存并迭代

保存为 markdown。可以提供这些后续动作：
- "要不要我用 SWOT 或 PESTLE 分析来**压力测试这套模式**？"
- "要不要我**为这些收入来源设计定价策略**？"
- "要不要我**围绕这套模式搭建一份战略画布**？"
- "要不要我**找出滩头细分市场**？"

## 注意事项

- **创业画布**是新产品推荐的起点——它把战略与商业模式分开，并覆盖了商业模式画布和精益画布遗漏的内容（愿景、取舍、指标、不能/不会）
- **精益画布**最适合追求速度和验证假设——不要想太多，但要注意它把战略和商业模式混在了同一份产物里
- **商业模式画布**更适合需要讲清各部分如何连接的成熟业务，但缺少战略部分（愿景、取舍、指标）
- **价值主张**是讨论产品市场契合时最锋利的工具
- 在「全部」模式下，标出各框架结论一致的地方（强信号）和不一致的地方（需要进一步调查）
