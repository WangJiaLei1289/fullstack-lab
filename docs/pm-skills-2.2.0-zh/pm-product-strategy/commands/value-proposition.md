# /value-proposition —— 价值主张设计

使用 6 部分 JTBD 模板，为产品或功能设计一份清晰、有说服力的价值主张。它是 Strategyzer 价值主张画布的替代方案，从客户出发，聚焦于实际结果。

## 调用方式

```
/value-proposition AI writing tool for non-native English speakers
/value-proposition [upload pitch deck, PRD, or competitive analysis]
/value-proposition                    # asks about your product
```

## 工作流程

### 第 1 步：理解产品与市场

接受来自以下渠道的背景信息：
- 产品描述（口头或书面）
- 上传的文档（融资路演演示文稿、PRD、竞品分析）
- 需要打磨的现有价值主张

关键问题：
- 产品是做什么的？面向谁？
- 目前有哪些替代方案或变通做法？
- 你手上有哪些客户洞察或调研？

### 第 2 步：构建价值主张

应用 **value-proposition** 技能，产出 6 部分模板：

```
## 价值主张：[产品]

### 面向 [细分市场]：

1. **Who（是谁）**：[目标用户画像与特征]
2. **Why（为什么）**：[他们想完成的任务、期望的结果]
3. **What Before（之前是什么）**：[他们当前痛苦的现实——现有工具、摩擦、变通做法]
4. **How（如何做）**：[你的解决方案——交付价值的具体特性与能力]
5. **What After（之后是什么）**：[改善后的结果——什么变得可能了]
6. **Alternatives（替代方案）**：[没有你他们会用什么，以及你为什么更好]

### 价值主张陈述
[一句话：对于 [需要什么] 的 [谁]，[产品] 是一款 [品类]，能够 [带来什么收益]。不同于 [替代方案]，我们 [差异点]。]

### 价值主张陈述（可复用）
- 营销：[...]
- 销售：[...]
- 新手引导：[...]
```

如果用户有多个细分市场，就为每个细分市场各做一份价值主张。

### 第 3 步：保存并提供后续选项

保存为 markdown。可以提供：
- "要不要我用价值曲线**把它与竞品做对比**？"
- "要不要我**围绕这个价值主张搭建完整战略**？"
- "要不要我用它**做一份精益画布**或**创业画布**？"
- "要不要我**基于这些价值主张陈述生成营销信息**？"

## 注意事项

- 这个模板从客户出发（Who/Why），再走向解决方案——而 Strategyzer 的画布把产品放在左边
- 每份价值主张都是针对特定细分市场的——不同细分市场要用不同的价值主张
- 用价值曲线（蓝海战略）在关键要素上把你的产品与竞品做可视化对比
- 价值主张只是产品战略的一个要素——要看到全貌请用 `/strategy`
