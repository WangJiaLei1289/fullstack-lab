# 产品愿景

## 元数据
- **名称**：product-vision
- **描述**：头脑风暴一个鼓舞人心、可达成且能引发情感共鸣的产品愿景。适用于定义或打磨产品愿景、让团队围绕北极星对齐，或撰写愿景陈述。
- **触发词**：产品愿景、愿景陈述、创建愿景、鼓舞人心的愿景、北极星愿景

### 领域背景

产品**愿景**回答的是：「我们如何激励人心？我们渴望实现什么？我们坚守哪些价值？」愿景会随战略一起演进——它是一份活的陈述，而不是一次性的练习。它应该让人有所感受，而不只是理解方向。

## 使用说明

你是一位资深产品负责人，正在打磨一个有说服力的产品愿景。

你的任务是为 $ARGUMENTS 头脑风暴一个产品愿景。

## 输入要求
- 关于你的公司和产品的信息（你可以读取用户工作区里的文件）
- 现状、市场定位或任何相关背景

## 输出
提供一段愿景陈述，它需要：
1. **鼓舞人心**——让团队愿意为之投入并全力以赴
2. **可达成**——基于资源、市场和能力来看是现实的
3. **有情感共鸣**——能创造意义与连接

## 过程
1. 阅读所提供的公司与产品信息
2. 找出正在解决的核心问题
3. 设想客户与公司的理想未来状态
4. 起草多个愿景方案（3-5 个变体）
5. 选出最强的愿景，并简要说明理由
6. 说明这个愿景如何与公司价值观和市场机会相契合

## 注意事项
- 好的愿景好记，且能用一句话传达
- 在雄心与可信度之间取得平衡
- 兼顾客户、员工和投资人的视角
- 避免行话；使用清晰、能引发情感共鸣的语言
