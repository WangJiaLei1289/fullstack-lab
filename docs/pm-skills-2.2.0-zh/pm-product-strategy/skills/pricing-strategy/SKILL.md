## 定价策略

设计一套以价值交付、竞争定位和付费意愿为基础的定价策略。

### 背景

你正在为 **$ARGUMENTS** 制定定价策略。

如果用户提供了文件（竞品定价、调研数据、财务模型或用量数据），先读取它们。必要时用网络搜索调研竞品定价。

### 使用说明

1. **理解交付的价值**：
   - 核心价值主张是什么？
   - 客户的替代方案是什么（以及它的成本）？
   - 产品能带来哪些可量化的结果？（节省时间、增加收入、降低成本）
   - 基于这份价值，客户的付费意愿有多高？

2. **评估定价模型**——推荐最合适的：

   | 模型 | 最适合 | 示例 |
   |---|---|---|
   | **统一费率** | 简单产品、成本可预测 | Basecamp（每月固定 99 美元） |
   | **按席位** | 协作工具、团队型产品 | Slack、Figma |
   | **按用量** | 基础设施、API 产品 | AWS、Twilio |
   | **分层** | 用户细分差异明显的产品 | 多数 SaaS（Free/Pro/Enterprise） |
   | **免费增值** | 有病毒传播/网络效应的产品 | Spotify、Notion |
   | **免费增值 + 按用量** | 平台型产品 | Vercel、OpenAI API |
   | **基于价值** | 高影响力的企业级工具 | Salesforce、Palantir |

3. **分析竞品定价**：
   - 梳理竞品的定价套餐及所含内容
   - 明确你的产品所处的位置（高端、中端、平价）
   - 找出定价空白或机会
   - 记录行业通行的定价惯例

4. **设计定价结构**：
   - **套餐**：定义 2-4 个差异清晰的套餐
   - **功能切分**：哪些功能放进哪个套餐？（用价值指标，而不是随意设定的限制）
   - **价值指标**：按什么单位收费？（用户数、事件数、存储量、API 调用量）
   - **锚定定价**：把最受欢迎的套餐做成看起来理所当然的选择
   - **年付折扣**：通常是月付价格的 15-20% off

5. **估算价格敏感度**：
   - Van Westendorp 价格敏感度测试（如有调研数据）：
     - 太便宜 → 担心质量
     - 便宜 → 性价比好
     - 贵 → 开始犹豫
     - 太贵 → 不会购买
   - 也可以基于竞品定价和交付价值进行估算

6. **规划定价实验**：
   - 对定价页面做 A/B 测试（不同价格点、套餐名称、功能组合）
   - 通过创始人主导的销售对话测试付费意愿
   - 用不同价格锚点做落地页测试
   - 按价格点对转化率做同期群分析

7. **输出定价建议**：
   ```
   Recommended Model: [Model type]
   Value Metric: [What you charge on]

   | Tier | Price | Target Segment | Key Features | Positioning |
   |---|---|---|---|---|

   Key Assumptions:
   - [Assumption] → [How to test]

   Risks:
   - [Risk] → [Mitigation]
   ```

一步一步思考。保存为 markdown。标出任何需要在发布前验证的假设。
