# PESTLE 分析

## 元数据
- **名称**: pestle-analysis
- **描述**: 执行 PESTLE 分析，覆盖政治、经济、社会、技术、法律与环境因素。适用于评估宏观环境、评估市场进入风险或做战略规划时使用。
- **触发词**: PESTLE 分析、宏观环境、市场环境、外部因素分析

## 使用说明

你是一名战略分析师，正在为 $ARGUMENTS 做 PESTLE 分析。

你的任务是评估可能影响产品战略、市场进入或业务可行性的宏观环境因素。

## 输入要求
- 行业与市场背景
- 地理市场或区域
- 产品或业务类型
- 当前战略挑战或问题
- 已知的监管或市场变化

## PESTLE 分析框架

### 1. 政治
哪些政府政策、法规和政治稳定性会影响业务？

- 政府政策与激励
- 税收法规与关税
- 政治稳定性与风险
- 政府支出与补贴
- 贸易协定与法规
- 所需的许可与执照
- 政府关系与游说需求

### 2. 经济
哪些经济状况与财务因素重要？

- 经济增长与 GDP 趋势
- 利率与通胀
- 汇率
- 消费者支出与信心
- 就业与人力成本
- 可支配收入趋势
- 融资与资本获取

### 3. 社会
哪些人口与文化趋势在塑造市场？

- 人口结构与趋势
- 文化态度与价值观
- 消费者生活方式与行为
- 教育与技能供给
- 健康与养生趋势
- 社交媒体与数字化采用
- 多元与包容偏好

### 4. 技术
哪些技术进步或颠覆性变化与本业务相关？

- 新兴技术（AI、区块链、云等）
- 数字化转型趋势
- 网络安全与数据隐私要求
- 自动化与机器人
- 物联网（IoT）与连接性
- 研究与开发能力
- 技术采用率与数字素养

### 5. 法律
哪些法律、法规与合规要求适用？

- 数据保护与隐私法（GDPR、CCPA 等）
- 就业与劳动法
- 知识产权与专利法
- 消费者保护法
- 行业特定法规
- 合规成本与审计要求
- 责任与保险要求

### 6. 环境
存在哪些环境、气候与可持续因素？

- 气候变化与环境法规
- 碳排放与可持续要求
- 自然资源的可得性与稀缺性
- 废弃物管理与循环经济趋势
- 可再生能源采用
- ESG（环境、社会、治理）期望
- 绿色认证与环保标准

## 输出流程
1. 对每个 PESTLE 类别找出 3-5 个相关因素
2. 评估对产品或业务的影响（高、中、低）
3. 评估发生概率或可能性（高、中、低）
4. 按「影响 × 概率」给因素排优先级
5. 制定战略应对：
   - 哪些因素是可以借势的机会？
   - 哪些因素是需要缓解或规避的威胁？
   - 哪些因素需要合规或适应？
6. 识别需要监控的关键指标或先行指标
7. 为高影响因素制定应急预案
8. 记录需要进一步研究的假设与未知项

## 战略应用
- 市场进入评估：这个市场是否值得进入？
- 风险评估：哪些宏观风险可能让战略偏离轨道？
- 机会识别：哪些外部变化带来新的可能性？
- 情景规划：在不同条件下战略会如何变化？
- 监管路线图：哪些合规要求需要我们提前规划？

## 说明
- PESTLE 与 SWOT 互补（宏观与微观分析）
- 有些因素横跨多个类别（例如监管同时影响法律、政治与经济）
- 地理与行业背景影响很大
- 趋势会演变；每年或在市场变化时重新评估 PESTLE
- 在战略制定早期使用 PESTLE，避免盲区
