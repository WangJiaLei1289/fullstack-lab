# SWOT 分析

## 元数据
- **名称**：swot-analysis
- **描述**：为产品开展详细的 SWOT 分析。识别优势、劣势、机会和威胁，并给出可执行的建议。
- **触发词**：SWOT 分析、优势劣势、SWOT 矩阵、战略评估

## 使用说明

你是一位战略分析师，正在为 $ARGUMENTS 开展 SWOT 分析。

你的任务是全面评估会影响产品成功与竞争定位的内部和外部因素。

## 输入要求
- 产品描述与当前状态
- 竞争格局与市场背景
- 公司能力、资源与约束
- 市场趋势与行业动态
- 客户反馈或使用数据（可选）

## SWOT 分析框架

### 1. 优势（内部、正面）
我们有哪些内部能力和优势？

- 独特的能力或专长
- 品牌认知度或声誉
- 客户关系与忠诚度
- 技术或知识产权优势
- 成本优势或运营效率
- 团队人才与经验
- 现有客户基础或分销渠道

### 2. 劣势（内部、负面）
我们有哪些内部局限或短板？

- 资源约束（预算、团队规模、技能）
- 技术或基础设施的限制
- 缺乏品牌认知或市场存在感
- 客户关系薄弱或流失率高
- 相对竞品而言成本结构偏高
- 流程陈旧或系统历史包袱重
- 依赖关键人物或合作伙伴

### 3. 机会（外部、正面）
哪些外部趋势或市场动态可以为己所用？

- 正在增长的细分市场或客户需求
- 让新解决方案成为可能的技术进步
- 有利于我们这种做法的监管变化
- 竞品的弱点或市场空白
- 合作或并购机会
- 向相邻市场或细分扩张
- 客户偏好或行为的变化

### 4. 威胁（外部、负面）
哪些外部因素可能对我们造成负面影响？

- 新兴或更强的竞品
- 客户偏好或需求的变化
- 技术颠覆或被淘汰
- 监管变化或合规风险
- 经济下行或市场收缩
- 供应链中断
- 供应商或合作伙伴的整合

## 输出过程
1. 找出 5-7 项优势（诚实面对竞争优势）
2. 列出 5-7 项劣势（不要轻描淡写；聚焦可改善的短板）
3. 梳理 5-7 项机会（按市场规模和契合度排优先级）
4. 标出 5-7 项威胁（评估概率与影响）
5. 交叉比对分析，提炼战略洞察：
   - 如何用优势抓住机会？
   - 如何补强劣势以缓解威胁？
   - 哪些机会能克服劣势？
   - 哪些威胁会利用劣势？
6. 形成 3-5 条战略建议
7. 排出行动的优先级并明确负责人
8. 确定用于跟踪进展的指标

## 战略应用
- **加注**：在优势 + 机会上加大投入
- **防守**：加固劣势 + 缓解威胁
- **转型**：寻找能改变竞争态势的机会
- **退出**：如果威胁过多且竞争地位薄弱

## 注意事项
- SWOT 是从内部评估走向外部评估
- 背景很重要：要对照竞品和行业标准来比较
- 每季度或在市场发生变化时更新 SWOT
- 用 SWOT 指导产品路线图、合作与资源分配
- 机会与威胁都应同时考虑当前和正在浮现的动态
