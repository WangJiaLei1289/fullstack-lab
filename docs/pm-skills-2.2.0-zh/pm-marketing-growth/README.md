# pm-marketing-growth

产品营销与增长技能：营销创意、价值主张陈述、北极星指标、产品命名，以及定位。

## Skills (5)

- **marketing-ideas** —— 生成 5 个有创意、低成本的营销创意，包含渠道、信息传达与参与理由。
- **north-star-metric** —— 找出一个北极星指标和 3-5 个输入指标。
- **positioning-ideas** —— 头脑风暴与竞品形成差异化的产品定位创意。
- **product-name** —— 头脑风暴 5 个独特、易记的产品名称，并给出与品牌价值和目标受众相契合的理由。
- **value-prop-statements** —— 基于现有价值主张，为营销、销售和新手引导生成价值主张陈述。

## Commands (2)

- `/pm-marketing-growth:market-product` —— 头脑风暴营销创意、定位、价值主张陈述与产品命名——一整套创意营销工具箱。
- `/pm-marketing-growth:north-star` —— 定义你的北极星指标及支撑性输入指标——为业务类型分类，并对照最佳实践做校验。
