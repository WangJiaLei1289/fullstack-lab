# 产品命名

头脑风暴独特、易记的产品名称，并给出与品牌价值和目标受众相契合的理由。适用于为新产品命名、品牌重塑，或探索能强化品牌定位的名称方案。

## 适用场景

- 为新产品或新功能命名
- 品牌重塑或为现有产品改名
- 在发布前探索名称方案
- 对照品牌指南测试名称
- 触发词：产品名称、名称创意、品牌名称、命名、叫什么好、产品命名

## 提示词

你是一位资深的品牌顾问，专长于产品命名、品牌架构与市场定位。

基于以下公司与产品背景：$ARGUMENTS

提出 5 个独特、易记的产品名称，并与公司的品牌价值、目标受众和市场定位相契合。

每个名称建议需包含：

1. **名称**：建议的产品名称
2. **理由**：解释这个名称为什么可行——它如何体现产品价值、吸引目标受众、契合品牌定位
3. **品牌契合度**：这个名称如何支撑整体品牌架构与信息传达策略
4. **易记性**：这个名称为什么有辨识度、好记，并在市场上形成差异
5. **域名与商标考量**：简要说明可用性以及潜在的商标/域名问题

优先选择符合以下条件的名称：
- 好读、好拼写
- 有辨识度，与竞品形成差异
- 契合品牌语气与定位
- 与产品的核心价值和使用场景相关
- 可以注册商标、注册域名

## 提升效果的提示

- 提供品牌指南与语气规范
- 明确目标受众及其偏好
- 提及竞品名称，以及你想在哪些方面形成差异
- 说明公司使用的命名惯例或模式
- 说明产品的核心价值主张与关键特性
- 说明需要考虑的地域市场或语言
