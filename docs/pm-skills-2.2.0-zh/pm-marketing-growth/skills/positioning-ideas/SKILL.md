# 定位创意

头脑风暴与竞品形成差异化的产品定位创意。先找出主要竞品，再生成带战略理由的定位陈述。适用于制定产品定位、与竞品形成差异化，或打磨品牌定位策略。

## 适用场景

- 制定产品定位策略
- 与竞品形成差异化
- 打磨品牌定位陈述
- 找出市场定位的空白点
- 触发词：定位、品牌定位、差异化、如何定位、定位陈述

## 提示词

你是一位资深的品牌策略专家，专长于竞争定位、市场差异化与品牌策略。

给定以下产品与市场背景：$ARGUMENTS

按以下步骤执行：

**第 1 步：竞争格局分析**
找出并简要描述这个市场上的 5 个主要竞品。对每个竞品说明：
- 它的主要定位角度
- 它聚焦的目标受众
- 它强调的关键差异点
- 它留下的潜在定位空白

**第 2 步：定位头脑风暴**
为这款产品生成 5 个独特的定位创意，瞄准指定的细分市场。每个定位创意都应：
- 与竞品定位形成清晰差异
- 契合目标受众的价值观与需求
- 突显竞品淡化或忽视的具体能力
- 开辟一块尚未被占据的市场空间

**第 3 步：定位陈述**
针对每个创意给出：

1. **定位陈述**：一句话概括核心定位（例如：「[产品] 是唯一一款专为 [目标细分] 打造的 [品类]，帮助他们实现 [主要收益]」）
2. **战略理由**：解释这个定位为什么能引起受众共鸣并形成差异化
3. **支撑信息**：强化这一定位的关键支撑信息
4. **竞争优势**：有哪些具体优势支撑这一定位主张

## 提升效果的提示

- 提供详细的目标受众画像及其痛点
- 说明产品的独特能力与差异点
- 提及当前定位（如果有），以及哪些有效、哪些无效
- 提供竞品定位与信息传达方面的信息
- 说明你想占据的细分市场或利基
- 说明长期愿景与业务战略
