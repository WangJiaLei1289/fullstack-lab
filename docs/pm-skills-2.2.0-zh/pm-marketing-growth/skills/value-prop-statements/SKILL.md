# 价值主张陈述

基于现有价值主张，为营销、销售和新手引导生成价值主张陈述。这些陈述会针对目标细分市场，强调收益并突显能力。非常适合用于撰写有针对性的营销内容、销售演示文稿和客户新手引导消息。

## 适用场景

- 撰写营销文案与推广内容
- 制作销售演示文稿与推介材料
- 打磨客户新手引导消息
- 开发针对不同细分市场的传达信息
- 触发词：价值主张陈述、营销文案、销售信息、价值陈述、定位文案

## 提示词

你是一位经验丰富的产品增长专家，专长于价值主张开发与有针对性的信息传达。

基于以下关于 $ARGUMENTS 的价值主张，开发一套完整的价值主张陈述，可用于营销、销售和新手引导场景。

每一条陈述都要满足：
- 直接针对某个具体的细分市场或使用场景
- 强调主要收益与期望结果
- 突显让这一收益成为可能的关键特性与能力
- 使用清晰、有说服力、能与受众共鸣的语言

## 示例框架（Canva）

为说明这一方法，以下是 Canva 的价值主张陈述：

1. **面向社交媒体营销人员**：Canva 让社交媒体营销人员无需昂贵的设计软件、也无需专门聘请设计师，就能轻松做出惊艳且符合品牌调性的设计。快速产出专业水准的图形，提升互动率，并在所有渠道上强化品牌一致性。

2. **面向小微企业主**：借助 Canva 直观的拖拽式界面和丰富的预制模板库，小微企业主能在几分钟内上线精美的营销活动。网站图形、社交帖子、传单和宣传物料都能做出专业设计的效果——全程不需要设计经验。

3. **面向内容创作者**：使用 Canva，内容创作者可以把精力放在讲故事上，减少在排版等设计琐事上的时间。借助针对不同平台定制的模板，规模化地产出一致、美观的内容，最终把更多时间留给受众互动和内容策略。

## 提升效果的提示

- 提供现有的价值主张或关键收益
- 明确目标细分市场及其痛点
- 说明产品特性与差异点
- 说明投放渠道（营销、销售、新手引导）
- 说明品牌语气或语调规范
