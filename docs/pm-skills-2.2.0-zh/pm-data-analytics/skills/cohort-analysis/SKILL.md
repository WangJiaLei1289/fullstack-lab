# 同期群分析与留存挖掘

## 目的
以同期群为单位分析用户参与度与留存模式，识别用户行为、功能采用与长期参与度的趋势。把定量洞察与定性研究建议结合起来。

## 工作方式

### 第 1 步：读取并校验数据
- 接收含用户同期群信息的 CSV、Excel 或 JSON 数据文件
- 校验数据结构：同期群标识、时间周期、参与度指标
- 检查缺失值与数据质量问题
- 汇总关键统计（同期群规模、日期范围、可用指标）

### 第 2 步：生成定量分析
- 计算同期群留存率与参与度趋势
- 识别留存曲线、流失模式与异常
- 计算各同期群的功能采用率
- 计算环比或周期环比变化
- 如需要，用 pandas 与 numpy 生成 Python 分析脚本

### 第 3 步：创建可视化
- 生成留存热力图（同期群 × 时间周期）
- 生成展示同期群演进的折线图
- 为功能采用搭建对比图
- 可视化流失点与参与度趋势
- 输出为交互式图表或静态图片

### 第 4 步：识别洞察与模式
- 找出一个或多个显著模式：
  - 特定同期群的早期流失
  - 后期参与度变化
  - 功能采用集群
  - 季节性或时间性趋势
- 突出意外发现与偏差
- 对比同期群表现以建立基线

### 第 5 步：建议后续研究
- 推荐定性研究方法：
  - 对流失用户做定向访谈
  - 对高参与同期群做功能使用问卷
  - 关键交互路径的会话回放
  - 高留存与低留存同期群的得失分析
- 设计后续定量研究
- 建议 A/B 测试或功能实验

## 用法示例

**示例 1：上传 CSV 数据**
```
上传 cohort_engagement.csv，字段为：cohort_month、weeks_active、
user_id、feature_x_usage、engagement_score

请求：「分析留存模式，并找出 2025 年第四季度同期群相较第三季度
表现不佳的原因」
```

**示例 2：描述数据格式**
```
「我有 2025 年 1-12 月的月度用户同期群。每行包含：
同期群日期、用户 ID、购买频率、支持工单。
分析哪些同期群的长期留存最好。」
```

**示例 3：功能采用分析**
```
上传含同期群采用数据的 feature_usage.xlsx。

请求：「对比我们新功能在各同期群的采用曲线。
哪些同期群采用最快？有模式吗？」
```

## 关键能力

- **数据读取**：导入 CSV、Excel、JSON、SQL 查询结果
- **留存分析**：计算并可视化随时间的留存率
- **同期群对比**：跨同期群比较指标
- **异常检测**：标出异常模式或流失
- **Python 脚本**：生成可复用的分析代码，便于持续分析
- **可视化**：生成热力图、图表与交互式看板
- **研究设计**：建议定向后续研究与访谈方法
- **统计摘要**：提供定量指标与相关性分析

## 最佳实践提示

1. **带上时间维度**：提供跨多个时间周期的数据
2. **清晰定义同期群**：明确同期群分组方式（注册月份、功能上线日期等）
3. **提供背景**：说明期间的产品改动、上线或事件
4. **多个指标**：包含留存、参与度、功能使用、收入等
5. **数据充足**：至少 3-4 个同期群，才能识别有意义的模式
6. **明确输出要求**：说明要可视化、Python 脚本还是研究建议

## 输出格式

你会收到：
- **数据摘要**：同期群概览与数据质量评估
- **定量发现**：关键指标、留存率与趋势分析
- **可视化**：展示留存曲线、采用模式的图表
- **模式识别**：从数据中提炼的 2-3 个重要洞察
- **研究建议**：具体的定性与定量后续动作
- **分析脚本**（如要求）：可复现分析的 Python 代码
- **后续动作**：基于发现排好优先级的行动
