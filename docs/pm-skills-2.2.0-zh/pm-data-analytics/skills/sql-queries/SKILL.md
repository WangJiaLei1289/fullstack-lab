# SQL 查询生成器

## 目的
把自然语言需求转化为跨多种数据库平台的优化 SQL 查询。这个技能帮助产品经理、分析师和工程师无需手工处理语法，就能生成准确的查询。

## 工作方式

### 第 1 步：理解你的数据库表结构
- 如果你提供表结构文件（SQL、文档或图描述），我会读取并分析
- 提取表名、字段定义、数据类型与关系
- 识别主键、外键与索引策略

### 第 2 步：处理你的请求
- 明确你需要查询或分析的具体数据
- 确认 SQL 方言（BigQuery、PostgreSQL、MySQL、Snowflake 等）
- 询问其他要求（筛选、聚合、排序）

### 第 3 步：生成优化查询
- 写出充分利用数据库结构的 SQL
- 加入注释解释复杂逻辑
- 为大表补充性能考量
- 如适用，提供替代写法

### 第 4 步：解释并测试
- 用自然语言解释查询逻辑
- 建议如何测试或校验结果
- 提供性能优化技巧
- 如果需要，生成测试脚本或示例数据

## 用法示例

**示例 1：基于表结构文件查询**
```
上传 database_schema.sql 文件，然后说：
「生成一条查询，找出最近 30 天注册、
且至少有 5 次活跃会话的用户」
```

**示例 2：基于图描述查询**
```
「这是我的数据库：Users 表（id, email, created_at），Sessions 表
（id, user_id, timestamp, duration）。生成一条查询，算 2026 年 1 月
每个用户的平均会话时长。」
```

**示例 3：复杂分析查询**
```
「写一条 BigQuery 查询，按地区和客户层级分析我们的收入，
并包含同比增长率。」
```

## 关键能力

- **多方言支持**：支持 BigQuery、PostgreSQL、MySQL、Snowflake、SQL Server
- **文件读取**：读取表结构文件、SQL 导出文件与数据文档
- **查询优化**：建议索引、分区与性能改进
- **解释说明**：拆解查询，便于学习与写文档
- **测试**：可生成测试查询与示例数据脚本
- **脚本执行**：为你的数据库生成可执行的 SQL 脚本

## 最佳实践提示

1. **提供背景**：分享你的数据库表结构
2. **具体描述**：清楚说明需要什么数据以及筛选条件
3. **说明数据库**：指明你用的 SQL 方言
4. **带上约束**：说明数据量、时间范围与性能要求
5. **指定格式**：如果需要特定输出，说明查询结果的格式

## 输出格式

你会收到：
- **SQL 查询**：可直接上线的带注释 SQL
- **解释说明**：这条查询做什么、如何运作
- **性能提示**：优化技巧与注意事项
- **测试脚本**（如要求）：示例数据与校验查询
