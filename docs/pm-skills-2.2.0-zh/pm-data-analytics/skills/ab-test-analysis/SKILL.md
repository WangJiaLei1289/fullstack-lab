## A/B 测试分析

以统计严谨性评估 A/B 测试结果，并把发现转化为清晰的产品决策。

### 背景

你正在为 **$ARGUMENTS** 分析 A/B 测试结果。

如果用户提供了数据文件（CSV、Excel 或分析导出文件），直接读取并分析。需要统计计算时，生成 Python 脚本。

### 使用说明

1. **理解实验**：
   - 待验证的假设是什么？
   - 改动了什么（实验组）？
   - 主指标是什么？有哪些护栏指标？
   - 测试跑了多久？
   - 流量如何切分？

2. **校验实验设置**：
   - **样本量**：样本是否足以检测出预期效应？
     - 使用公式：n = (Z²α/2 × 2 × p × (1-p)) / MDE²
     - 若功效不足（<80%）要指出
   - **时长**：测试是否至少覆盖 1-2 个完整业务周期？
   - **随机化**：有无样本比例失衡（SRM）的迹象？
   - **新奇／首因效应**：是否有足够时间让初始行为变化消退？

3. **计算统计显著性**：
   - **转化率**：对照组与实验组
   - **相对提升**：(实验组 - 对照组) / 对照组 × 100
   - **p 值**：用双尾 z 检验或卡方检验
   - **置信区间**：差值的 95% 置信区间
   - **统计显著性**：p < 0.05 吗？
   - **实际显著性**：这个提升对业务有意义吗？

   如果用户提供原始数据，生成并运行 Python 脚本来计算这些值。

4. **检查护栏指标**：
   - 是否有护栏指标（收入、参与度、页面加载时间）变差？
   - 主指标赢了但护栏指标变差，可能并不是真的赢

5. **解读结果**：

   | 结果 | 建议 |
   |---|---|
   | 显著正向提升，护栏指标无问题 | **发布它**——全量推给 100% |
   | 显著正向提升，但护栏指标有隐忧 | **调查**——发布前先弄清楚权衡 |
   | 不显著，但有正向趋势 | **延长测试**——需要更多数据或更大的效应 |
   | 不显著，且基本持平 | **停止测试**——未检测到有意义的差异 |
   | 显著负向提升 | **不要发布**——回滚到对照组，分析原因 |

6. **给出分析摘要**：
   ```
   ## A/B 测试结果：[测试名称]

   **假设**：[我们预期什么]
   **时长**：[X 天] | **样本**：[N 对照组 / M 实验组]

   | 指标 | 对照组 | 实验组 | 提升 | p 值 | 是否显著？ |
   |---|---|---|---|---|---|
   | [主指标] | X% | Y% | +Z% | 0.0X | 是／否 |
   | [护栏指标] | ... | ... | ... | ... | ... |

   **建议**：[发布 / 延长 / 停止 / 调查]
   **理由**：[为什么]
   **后续动作**：[要做什么]
   ```

一步一步思考。保存为 markdown。如果提供了原始数据，生成 Python 脚本来计算。
