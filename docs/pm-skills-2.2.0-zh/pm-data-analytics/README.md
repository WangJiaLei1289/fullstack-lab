# pm-data-analytics

面向产品经理的数据分析技能：SQL 查询生成与同期群分析。分析用户数据、生成查询，并识别留存模式。

## Skills (3) 技能

- **ab-test-analysis** — 分析 A/B 测试结果，给出统计显著性、样本量校验、置信区间与可执行的建议。
- **cohort-analysis** — 对用户参与度数据做同期群分析。
- **sql-queries** — 根据自然语言描述生成 SQL 查询。

## Commands (3) 命令

- `/pm-data-analytics:analyze-cohorts` — 对用户数据做同期群分析——留存曲线、功能采用率与参与度趋势。
- `/pm-data-analytics:analyze-test` — 分析 A/B 测试结果——统计显著性、样本量校验，并给出发布／延长／停止的建议。
- `/pm-data-analytics:write-query` — 从自然语言生成 SQL 查询——支持 BigQuery、PostgreSQL、MySQL 等。
