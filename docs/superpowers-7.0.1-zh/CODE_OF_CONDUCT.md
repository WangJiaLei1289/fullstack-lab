# Prime Radiant 社区行为准则

## 我们的承诺

我们承诺让我们的社区对所有人都是欢迎、安全且公平的。

我们致力于营造一种尊重并促进每个人尊严、权利与贡献的环境，不论其特征如何，包括种族、民族、种姓、肤色、年龄、身体特征、神经多样性、残障、生理性别或社会性别、性别认同或表达、性取向、语言、哲学或宗教、民族或社会出身、社会经济地位、教育水平或其他身份。凡本着善意并遵守本准则参与的人，都享有同等的参与特权。

Prime Radiant 社区行为准则的各项规定及其执行，平等适用于所有参与 Prime Radiant 社区的人，包括 Prime Radiant 团队的成员。

## 鼓励的行为

在承认社会规范存在差异的同时，我们都努力达到社区对正向行为的期望。我们也理解，受文化、背景或母语影响，我们的言行可能被解读出与初衷不同的意思。

基于这些考虑，我们同意彼此用心相待，并以体现我们共同价值观的方式行事，包括：

1. 尊重**我们社区的目的**、我们的活动以及我们的聚会方式。
2. **友善而诚实**地与他人互动。
3. 尊重**不同的观点**与经历。
4. 对自身的行为与贡献**承担责任**。
5. 得体地给予和接受**建设性反馈**。
6. 一旦造成伤害，承诺**修复伤害**。
7. 以其他促进并维系**社区福祉**的方式行事。

## 受限行为

我们同意在社区中限制以下行为。这些行为的实例、威胁与宣扬，均属违反本行为准则。

1. **骚扰。** 在对方明确请求停止后，仍侵犯其明确表达的边界，或继续不必要的个人关注。
2. **人身攻击。** 对社区成员或群体发表侮辱、贬损或轻蔑的言论。
3. **挑起冲突。** 故意参与旨在引发争吵或敌对环境的讨论。
4. **刻板印象或歧视。** 基于不可改变的身份或特征来评判他人的性格或行为。
5. **性化。** 在社区语境或目的下，做出通常会被认为不适当亲密的行为。
6. **侵犯保密。** 未经许可分享或利用他人的个人或隐私信息。
7. **危害。** 对任何人或群体造成、鼓励或威胁暴力或其他伤害。
8. 以其他**威胁社区福祉**的方式行事。

### 其他限制

1. **分裂性话题。** 讨论与整个社区无关的煽动性话题。
2. **攻击性内容。** 任何具有攻击性、或违反其他受限行为的文字或图像，包括出现在用户名、个人资料、状态、头像或其他公开展示的标识中的那些。
3. **误导性身份。** 以任何理由冒充他人，谎称自己与 Prime Radiant 或任何公司有关联，或假装成别人以逃避处理。
4. **未注明来源。** 未恰当注明你所贡献内容的来源，或把他人创作的作品当作自己的。
5. **广告与推广材料。** 分享营销或其他商业内容、邀请链接或无关的自我推广，以及购买、交易或索要捐赠。
6. **垃圾帖。** 灌水，包括但不限于：短时间内发布大量消息、无关内容或过多链接。
7. **未经请求的提及与私信。** 通过过度提及他人用户名或回复进行骚扰，或未经明确邀请给他人发私信。
8. **不负责任的传播。** 未能负责任地呈现包含、链接或描述上述任何受限行为的内容。
9. 其他可被合理认定为**不专业**或**不当**的行为。

## 报告问题

即使社区成员都在尽力协作，彼此之间也可能出现紧张。并非每一次冲突都构成违反行为准则；本准则强化那些有助于避免冲突、减少伤害的鼓励行为与规范。我们欢迎你报告任何顾虑，即使看起来很轻微——它们有助于识别那些单独看不值得担心、但合在一起可能更严重的行为模式。

一旦发生事件，及时报告很重要。要报告社区任何地方可能存在的违规，请发邮件至 [conduct@primeradiant.com](mailto:conduct@primeradiant.com)。在 Prime Radiant 的 Discord 服务器上，你可以在公开频道提及 `@moderators`，也可以通过 `#support-ticket` 频道创建支持工单来报告。如果你需要举报 Prime Radiant 团队的某位成员，可以联系 Kattni（[kattni@primeradiant.com](mailto:kattni@primeradiant.com)）或 Drew（[drew@primeradiant.com](mailto:drew@primeradiant.com)）。

社区版主会认真对待违规报告，并尽一切努力及时回应。他们会调查所有违反行为准则的报告，查看消息、日志和录音，或访谈证人及其他参与者。社区版主会尽量让调查与处理过程保持透明，同时优先保证安全与保密。为践行这些价值，处理措施会在涉事各方之间私下进行，但向整个社区通报也可能是双方达成一致的解决方案的一部分。如果版主认定需要公开声明，所有受害者和报告者的身份都将保密，除非当事人另有指示。

报告中请包含：

- **你的联系方式**，以便团队在需要跟随时能联系到你。
- **任何涉及人员的姓名（真实姓名、昵称或化名）。** 如果你之外还有其他证人，也请尽量列出。
- **事件发生的时间与地点。** 请尽量具体。
- **你对事件经过的陈述。** 如果有公开记录（例如 Discord 或 GitHub 消息），请附上链接。
- **你认为与事件相关的任何额外背景。**
- **你是否认为该事件仍在持续。**
- **你是否认为团队任何成员在处理该事件时存在利益冲突。**
- **你认为合适的纠正措施**（如果有）。
- **你认为团队应该知道的任何其他信息。**

对于报告者及事件细节，版主有义务保密。

## 报告后续

你会在 24 个工作小时内收到确认收到报告的回复。

如果团队成员本身是被指名的一方，他将不参与任何讨论，也不会获得来自报告者的任何保密细节。

如果版务团队中有人认为自己在处理所报告的问题时存在利益冲突，他会告知其他团队成员，并回避与该问题相关的任何讨论。作出这一声明后，他将不会获得来自报告者的任何保密细节。

团队会立即审查事件并确定：

- 发生了什么。
- 该事件是否构成违反行为准则。
- 被报告者是谁。
- 这是持续中的状况，还是对任何人有身体安全威胁。

如果确定这是持续中的事件或存在身体安全威胁，团队的当务之急是保护所有涉事人员。这意味着在团队认为情况已经结束、每个人都已身体安全之前，可能会推迟正式回应。

版务团队会在一周内向提交报告的人作出回应，给出处理结果，或解释为何情况尚未解决。

团队确定最终处理措施后，会联系报告者告知将采取什么措施（如果有）。他们会考虑报告者对处理是否适当的反馈，但不保证会据此行动。

最后，为保持报告与处理流程的透明，团队会尽可能发布事件的公开透明度报告。如果事件的具体情况无法在保护匿名的情况下公开，或存在持续伤害的可能，则可能不发布公开报告。

## 处理与修复伤害

如果社区版主的调查认定本行为准则遭到违反，可按以下处理阶梯决定如何最好地修复伤害，依据是该事件对涉事个人和整个社区的影响。根据违规的严重程度，可以跳过阶梯中较低的层级。

1) 警告
   1) 情形：涉及单次事件或一系列事件的违规。
   2) 后果：社区版主发出的私下书面警告。
   3) 修复：修复的例子包括私下书面道歉、承认责任，以及就期望寻求澄清。
2) 临时限制活动
   1) 情形：此前已被警告过的违规再次发生，或较严重违规的首次发生。
   2) 后果：私下书面警告，并附带限时的冷却期，用以强调情况的严重性，并给涉事社区成员时间消化该事件。冷却期可以限定于特定沟通渠道，或与特定社区成员的互动。
   3) 修复：修复的例子包括道歉、利用冷却期反思行为与影响，以及在冷却期结束后对重新进入社区空间保持审慎。
3) 临时停权
   1) 情形：社区版主已尝试用警告处理过的反复违规模式，或单次严重违规。
   2) 后果：私下书面警告，并附带恢复所需的条件。通常，临时停权会给被停权者时间反思其行为与可能的纠正措施。
   3) 修复：修复的例子包括尊重停权的精神、满足规定的恢复条件，以及在停权解除后审慎考虑如何重新融入社区。
4) 永久封禁
   1) 情形：其他阶梯措施未能解决的反复违反行为准则模式，或严重到社区版主认定无法在保留此人为成员的情况下保证社区安全的违规。
   2) 后果：移除对全部社区空间、工具和沟通渠道的访问权限。通常，永久封禁应极少使用，应有充分理由，且只有在其他补救措施都无法改变行为时才诉诸使用。
   3) 修复：在这种严重程度下，不存在可能的修复。

这一处理阶梯意在作为指南。它不限制社区管理者根据我们社区的最大利益自行斟酌判断。

## 适用范围

本行为准则适用于所有社区空间，包括 GitHub 和 Prime Radiant 的 Discord 服务器。当个人在公开或其他场合正式代表社区时，也同样适用。代表社区的例子包括：使用官方电子邮件地址、通过官方社交媒体账号发帖，或在线上/线下活动中担任受任代表。

在 Prime Radiant 官方空间之外的行为，如果构成某种模式、或对 Prime Radiant 社区构成潜在风险，也可能被视为报告的佐证。
