# 会话对话记录的上下文安全

一条对话记录可能超过一兆字节，也可能内嵌一整段历史。打印一整条记录可能撑爆做诊断的那个会话的上下文。每个读取会话文件的人 —— 无论是控制器还是子代理 —— 每次面对每个文件，都要遵守这些规则。

1. **先度量，再读取。**

   ```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # long lines
   ```

2. **绝不用 `cat` 或 `grep` 直接取内容。** 先拿行号和计数（`grep -n … | cut -d: -f1`、`jq -r '.type' | sort | uniq -c`），再从具体行里取小字段（`sed -n Np | jq -c '{…}'` 或 `| cut -c1-500`）。使用发现阶段为当前这种来源确立的字段提取命令。
3. **把超过 500 字符的内容收窄。** 如果某条记录的一条命令返回超过 500 个字符，就收紧字段或切片。
4. **只读。** 绝不修改、移动或删除会话文件。
