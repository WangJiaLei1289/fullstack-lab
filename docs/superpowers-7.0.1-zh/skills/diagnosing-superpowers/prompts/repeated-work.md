维度：重复工作

找出会话做过不止一次的工作。

1. 把每次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 是：读/编辑/写操作的文件路径；shell 调用的命令文本（去掉末尾空白；保留完整命令）；子代理分派时的 `description` 加上提示词的前 80 个字符；搜索时的查询。
2. 按 `(tool, key)` 分组，报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子代理分派 | 2，且 description 相同 | |

3. 对每个组，检查重复之间是否有任何变化（对该文件的写入、一次 compaction、一次人类纠正）。说明属于哪种情况：编辑之后的重新读取不算发现；compaction 之后的重新读取算作归因于该 compaction 的发现；中间什么都没有发生的重新读取本身就是一条发现。
4. 查找重新推导出的决定：助手文本得出了一个会话中此前已经说过的结论（同一个文件、同一个设计选择、同一条要运行的命令）。引用两处原文。
5. 每组一条发现，附首次和末次行号以及次数。
