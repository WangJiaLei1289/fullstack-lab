维度：磕绊

找出会话每一次停滞不前的节点。

来源如下；每一项都使用案例文件中有证据的记录含义和提取命令来定位行号：
- 被标记为错误、非零退出或显式失败记录的工具结果；
- 失败的 shell 命令（结果中为非零退出、「command not found」、「No such file」）；
- 重试：出错后在同一轮次内重新发出同一个工具调用；
- 被回退的编辑：一次编辑之后又出现一次把内容恢复为先前状态的编辑，或对会话碰过的文件执行 `git checkout`/`git restore`/`git revert`/`git reset`；
- 助手文本中的回头（「actually」「let me instead」「that was wrong」「I misread」）；
- 人类纠正：与助手紧邻的前一个动作矛盾或纠正该动作的人类提示词；
- 权限拒绝、钩子失败、API 错误、速率限制、被中止的轮次，以及任务中途触发的上下文溢出或 compaction。

对每个磕绊报告：行号、轮次、什么失败了，以及接下来发生了什么（同一轮次内恢复 / 在第 N 行稍后恢复 / 从未恢复）。把完全相同的重复失败合并为一条发现并附次数。
