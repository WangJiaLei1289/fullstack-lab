# Pi 工具映射

技能用动作说话（「派发一个子代理」「建一个待办」「读一个文件」）。在 Pi 上，这些动作对应下面这些工具。

| 技能要求的动作 | Pi 的对应做法 |
| --- | --- |
| 派发一个子代理（`Subagent (general-purpose):` 模板） | 用已安装的子代理工具，例如 `pi-subagents` 提供的 `subagent`（如果装了的话） |
| 任务跟踪（「建一个待办」「标记为完成」） | 用已安装的待办/任务工具（如果装了的话），否则就在计划里或 `TODO.md` 里跟踪任务 |

## 子代理

Pi 核心不自带标准的子代理工具。`pi-subagents` 包是一个很强的可选搭档，它提供了一个 `subagent` 工具，支持单代理、链式、并行、异步、分叉上下文以及恢复/状态等工作流。如果没有可用的子代理工具，不要编造 `Task` 调用；在当前会话里顺序执行，或者说明可选子代理能力尚未安装。

## 任务列表

Pi 核心不自带标准的任务列表工具。如果装了待办/任务扩展，就用它文档里写的工具。否则就用 Superpowers 的计划文件、Markdown 里的检查清单，或仓库内的 `TODO.md` 来跟踪任务。较旧的 Superpowers 文档可能会提到 `TodoWrite`；把它当作上面说的任务跟踪动作。
