# Claude Code 工具说明

Claude Code 是参考宿主环境：技能用的是它的词汇（用 `Agent` 派发子代理、用待办、用 `Skill`）。
这些说明只覆盖一处——Claude Code 能在哪里以比技能默认形态更便宜的方式跑完一个计划。
这项做法由你的搭档主动开启，不改变技能所要求的任何东西。

## 子代理驱动开发的更省成本编排

在 superpowers:subagent-driven-development 的一轮执行里，控制会话是最贵的一个位置：
它要读每一次派发的结果和每一份报告，而且通常跑在会话里能力最强的模型上。
Claude Code 支持嵌套子代理（默认在主对话之下三层；`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` 可以调整），
所以整个循环可以下沉一层运行。

当你的搭档这样做——或者说这个会话的模型太贵、不该把算力花在协调上——就用一个中层模型派发一个编排器子代理，
把计划路径和「端到端使用 superpowers:subagent-driven-development」的指令一起交给它。
编排器按该技能的模型选择（Model Selection）自行派发实现者和评审者；工作区和账本（ledger）都在磁盘上，多这一层不会丢东西。
它的最后一条消息必须原样带上「Rulings I made」清单——那份清单是把决定送到你搭档手上的通道，你要原样转达，不要做总结。

只对整个计划这样做。把单个任务的派发再套一层毫无收益，反而多占一个位置。
