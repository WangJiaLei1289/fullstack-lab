# 技能设计中的说服原则

## 概述

LLM 会和人类一样回应同样的说服原则。理解这套心理学，能帮你设计出更有效的技能——不是为了操纵，而是为了确保关键实践即使在压力下也被遵守。

**研究基础：**Meincke 等（2025）在 N=28,000 次 AI 对话中测试了 7 条说服原则。说服技巧让服从率提高了一倍以上（33% → 72%，p < .001）。

## 七条原则

### 1. 权威（Authority）
**它是什么：**对专业能力、资质或官方来源的服从。

**在技能里怎么起作用：**
- 祈使语气：「YOU MUST」「Never」「Always」
- 不给谈判空间的表述：「No exceptions」
- 消除决策疲劳与自我合理化

**何时使用：**
- 强制纪律的技能（TDD、验证要求）
- 对安全至关重要的实践
- 已被确立的最佳实践

**示例：**
```markdown
✅ 在写测试之前先写代码？删掉重来。没有例外。
❌ 在条件允许时可以考虑先写测试。
```

### 2. 承诺（Commitment）
**它是什么：**与先前的行动、声明或公开表态保持一致。

**在技能里怎么起作用：**
- 要求宣告：「Announce skill usage」
- 强制做出明确选择：「Choose A, B, or C」
- 使用跟踪：用 todo 管理检查清单

**何时使用：**
- 确保技能真的被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你调用某个技能时，必须（MUST）宣告："I'm using [Skill Name]"
❌ 考虑让你的搭档知道你在用哪个技能。
```

### 3. 稀缺（Scarcity）
**它是什么：**来自时限或有限可得性的紧迫感。

**在技能里怎么起作用：**
- 有时限的要求：「Before proceeding」
- 顺序依赖：「Immediately after X」
- 防止拖延

**何时使用：**
- 即时验证要求
- 时间敏感的工作流
- 防止「我稍后再做」

**示例：**
```markdown
✅ 完成一项任务后，必须立即（IMMEDIATELY）请求代码评审，然后再继续。
❌ 方便的时候再评审代码也不迟。
```

### 4. 社会认同（Social Proof）
**它是什么：**顺从他人的做法，或顺从被认为是常态的东西。

**在技能里怎么起作用：**
- 普遍化表述：「Every time」「Always」
- 失败模式：「X without Y = failure」
- 确立规范

**何时使用：**
- 记录普遍实践
- 对常见失败发出警告
- 强化标准

**示例：**
```markdown
✅ 检查清单不配待办跟踪 = 步骤会被跳过。每次都是。
❌ 有些人觉得待办列表对检查清单有帮助。
```

### 5. 共同体（Unity）
**它是什么：**共享身份、「我们感」、内群体归属。

**在技能里怎么起作用：**
- 协作式语言：「our codebase」「we're colleagues」
- 共同目标：「we both want quality」

**何时使用：**
- 协作型工作流
- 建立团队文化
- 非层级化的实践

**示例：**
```markdown
✅ 我们是同事，在一起干活。我需要你坦诚的技术判断。
❌ 你觉得我错了的话，大概应该告诉我。
```

### 6. 互惠（Reciprocity）
**它是什么：**回报所获好处的义务。

**在技能里怎么起作用：**
- 少用——容易让人觉得在操纵
- 技能里很少需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 好感（Liking）
**它是什么：**更愿意与自己喜欢的人合作。

**在技能里怎么起作用：**
- **不要用它来换取服从**
- 与坦诚反馈的文化相冲突
- 会制造谄媚

**何时避免：**
- 在强制纪律的场景里永远避免

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 强制纪律 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技巧 | 适度的权威 + 共同体 | 重压式权威 |
| 协作 | 共同体 + 承诺 | 权威、好感 |
| 参考 | 只求清晰 | 一切说服手段 |

## 为什么有效：心理学机制

**明线规则减少自我合理化：**
- 「YOU MUST」消除决策疲劳
- 绝对化语言消除「这算不算例外？」的疑问
- 明确的反自我合理化条款堵住具体漏洞

**执行意图塑造自动行为：**
- 清晰的触发条件 + 必需动作 = 自动执行
- 「当 X 时，做 Y」比「一般要做 Y」更有效
- 降低服从时的认知负担

**LLM 是准人类的（parahuman）：**
- 训练语料是人类文本，其中包含这些模式
- 训练数据里权威语言常常出现在服从之前
- 承诺序列（表态 → 行动）被大量建模
- 社会认同模式（大家都做 X）确立规范

## 合乎伦理地使用

**正当用途：**
- 确保关键实践被遵循
- 写出有效的文档
- 预防可预见的失败

**不正当用途：**
- 为私利而操纵
- 制造虚假的紧迫感
- 用内疚感换取服从

**检验标准：**如果对方完全理解了这项技巧，它是否仍然服务于对方的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服的七条原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 N=28,000 次 LLM 对话中测试了 7 条原则
- 使用说服技巧后服从率从 33% 提升到 72%
- 权威、承诺、稀缺最有效
- 验证了 LLM 行为的准人类模型

## 快速参考

设计技能时，问自己：

1. **它是什么类型？**（强制纪律、指导，还是参考）
2. **我想改变的是什么行为？**
3. **哪些原则适用？**（强制纪律通常用权威 + 承诺）
4. **我是不是叠加得太多了？**（不要七条全用）
5. **这合乎伦理吗？**（是否服务于对方的真实利益？）
