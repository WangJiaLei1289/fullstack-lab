# 预检扫描

属于 superpowers:subagent-driven-development 技能的一部分。在分派任务 1 之前运行一次。

在分派任务 1 之前，把计划扫一遍找冲突，边检查边写下你查了什么：

- 彼此矛盾、或与计划「全局约束」矛盾的任务
- 计划明确要求、但评审标准视为缺陷的东西（一个什么都没断言的测试、一段逻辑块的逐字重复）

扫描的输出是一张表，而不是一个结论。每一对共享某个文件或某个接口的任务占一行：这两个任务、一方产出什么与另一方消费什么、以及你发现了什么。每个任务占一行：它自己的文本是否自洽——它指定的测试与它指定的代码是否对得上，它创建的文件与它之后要改的文件是否对得上。没有这些行，就谈不上「扫描是干净的」。

把这张表写进账本。在开始执行之前，对你发现的每一件事都做出裁定——每一条发现都对着要求它的计划文字来裁——并把每条裁定记入账本。如果扫描是干净的，就不作评论地继续。对扫描暴露的每一处冲突做裁定——规格是约束性权威，计划是对它的论证——把裁定记在对应行旁边，然后分派任务 1。评审循环仍然是兜住那些只在实现中才浮现的冲突的网。
