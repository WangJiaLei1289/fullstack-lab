# 处理不是 DONE 的报告

属于 superpowers:subagent-driven-development 技能的一部分。

**DONE_WITH_CONCERNS：** 实现者完成了工作，但标出了疑虑。继续之前先读这些疑虑。如果疑虑关乎正确性或范围，就在评审前处理掉。如果它们只是观察（例如「这个文件越来越大了」），记下来，然后进入评审。

**NEEDS_CONTEXT：** 实现者需要未提供的信息。补上缺失的上下文，然后重新分派。

**BLOCKED：** 实现者无法完成该任务。评估阻塞项：
1. 如果是上下文问题，提供更多上下文，用同一个模型重新分派
2. 如果任务需要更多推理，用更强的模型重新分派
3. 如果任务太大，把它拆成更小的几块
4. 如果计划本身错了，裁定如何修正，把裁定记入账本，并在分派时把裁定一并带上重新分派

**绝不**忽略一次升级请求，也绝不强迫同一个模型在什么都没变的情况下重试。如果实现者说它卡住了，那就是有东西需要改变。
