# 找到会话历史

用这个环境里可用的工具和信息，解析你的搭档所说的那个会话。你的知识可以提示去哪找；但要用真实历史来核实结果。

使用宿主环境暴露的会话工具、已配置的存储、本地帮助、文档，或受限的文件系统检查。读文件内容前先度量文件，并遵循 context-safety.md。若环境指向归档或索引，就检查它们。已经提供了可用路径时，不需要再搜索。

用可获得的会话 id、工作目录、时间戳和匹配的对话内容来确认身份。仅凭「最近」不算确认。把被请求的会话与它的子会话、无关候选区分开。当现有证据无法区分时，就向对方索要缺失的识别信息。

对每个文件系统来源，从环境中取得它的完整绝对路径，把家目录简写和变量都展开。在案例记录和你给搭档的发现答复里使用同一个路径。

从观察到的记录或文档中，确立此次调查所需的记录含义。把人类消息与注入消息、工具结果、父代理的分派区分开。把工具调用与其结果配对。在计算总量前确立用量计数器的语义。不要从别的宿主环境推断格式，也不要把缺失字段当成 0。

在案例文件中记录确切来源、相关字段含义、支撑记录的位置、关联会话、被排除的看似合理的候选，以及未解决的信息。后续读者使用这份记录，而不是重复发现过程。如果历史缺失、无法访问或含糊不清，就说明具体的限制，并索要缺失的路径、导出文件或识别信息。
