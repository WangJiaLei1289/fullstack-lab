维度：成本与时间

说明 token 和实际耗时都花在哪里。

1. Token。只使用案例文件中已确立的用量记录和计数器含义。在计算总量之前，说明每个计数器是增量还是累计；对累计观测做差分，但不要把缺失的观测当成 0。报告有支持的总量最大的五个轮次，以及每个关联会话有支持的总量。
2. 实际耗时。使用案例文件中记录的有证据支持的时间戳字段、事件边界和单位。报告有支持的最长的五个轮次，以及相邻事件之间任何超过十分钟的间隔（空闲、等待关联会话，或等待你的搭档；只有在记录能显示时才说明是哪一种）。
3. 最大的工具结果：使用案例文件中有证据的工具结果记录，报告最大的十个结果及其工具和轮次。先对记录做度量，再提取有界内容。
4. Compaction（上下文压缩）：统计并定位那些在发现阶段已确立为 compaction 事件的记录。报告可获得的压缩前后计数器，以及每次压缩触发时会话正在做什么；无证据支持的字段标记为缺失。
5. 关联会话：统计数量，并为每个会话报告有支持的用量、时长和分派轮次。
6. 用数字报告在总量中占主导的轮次、子代理、工具或重复动作。除了对话记录显示的内容，不要推测某个轮次为什么昂贵。
